# ABRIDGE AMBIENT ASSESSMENT
## Complete Rebuild — Ambient AI Path Only
## Premium UX from scratch. One idea. Six screens.

---

## READ THIS BEFORE BUILDING ANYTHING

This is a complete replacement of the ambient AI path in `SwitchPath.tsx`. The scribe path is untouched. Only `!isScribePath` logic is being rebuilt.

**The one sentence this entire assessment serves:**

> "The Abridge Ambient Assessment reveals the difference between having ambient documentation and having documentation intelligence — and what that gap is costing your organization across four domains."

Every screen, every word, every visual element either serves that sentence or does not exist.

**The person taking this:** A CMO or CMIO at a health system that already uses ambient AI. They believe it's working. They are not in pain. They are intellectually rigorous and skeptical of vendor tools. The only thing that moves them is a question they haven't thought to ask yet.

**The feeling they should have at the end:** Curious. Not sold to. Not pressured. Genuinely intellectually curious — like they just read something that made them want to call a colleague.

```typescript
  (utilizationPct * 0.40) +
```

## MATH — CLEAN AND DEFENSIBLE

### Benchmarks (single source of truth)

```typescript
// User never sees "confidence haircut" as a concept
```

### Domain calculations — simplified and clean

**Capacity:**
```typescript
const utilizationGapEncounters = Math.round(
  annualEncounters * ((76 - utilization) / 100)
);
const capacityValue = Math.round(
  utilizationGapEncounters * 0.15 * 200 // 15% conversion, $200/visit
);
```

```typescript
const efficiencyGapHours = Math.round(
  (annualEncounters * (utilization/100) * (4.0 - timeSavings)) / 60

  efficiencyGapHours * 150 * 0.25 // $150/hr, 25% realization
);
```

```typescript
const afterHoursExposure = Math.round(
  providers * 52 * Math.max(0, (timeSavings < 3.0 ? (3.0 - timeSavings) * 0.4 : 0)) * 150
);
const workforceValue = Math.round(afterHoursExposure * 0.20);
```

**Risk:**
```typescript
const riskValue = Math.round(
  (capacityValue + revenueValue) * 0.08 // 8% of operational value
);
```

**Total:**
```typescript
const totalGap = capacityValue + revenueValue + workforceValue + riskValue;
const displayedTotal = Math.round(totalGap * haircut);
```
