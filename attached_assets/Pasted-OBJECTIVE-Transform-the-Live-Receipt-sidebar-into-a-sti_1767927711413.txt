OBJECTIVE:
Transform the Live Receipt sidebar into a sticky, real-time calculation companion that shows every input and derived value as the user builds their ROI model. It should feel like a Stripe payment receipt meets Bloomberg Terminal data panel - always visible, constantly updating, completely transparent.

CRITICAL RULES:
- Do NOT break existing calculations or state management
- Do NOT change branding, core colors, or typography scale
- Do NOT add playful animations (keep it 150-200ms ease-out, professional)
- Live Receipt must work on ALL pages: Adoption, Value Realization, Investment, and Results tabs
- All animations must be subtle highlights/transitions only

PART 1: STICKY POSITIONING & RESPONSIVE BEHAVIOR

DESKTOP (>1024px):
- Live Receipt becomes a sticky right sidebar
- Position: sticky, top: 24px
- Width: 360px fixed
- Right margin: 24px from viewport edge
- Scrolls with user but stays in viewport
- Main content area adjusts to accommodate (max-width: calc(100% - 420px))

TABLET (768px - 1024px):
- Live Receipt remains in right column but not sticky
- Width: 320px
- Normal scroll behavior

MOBILE (<768px):
- Live Receipt becomes a collapsible bottom sheet
- Collapsed state: Fixed bottom bar, 60px height
- Shows: "💰 Net Annual Gain: $XXX,XXX | XX.Xx ROI  ↑"
- Tap or swipe up to expand to 80% viewport height
- Expanded state: Scrollable, with close handle at top
- Close by swiping down or tapping outside

IMPLEMENTATION:
- Use position: sticky on desktop
- Use transform: translateY() for mobile bottom sheet
- Smooth transitions (300ms ease-out)
- Remember expanded/collapsed state in session storage

PART 3: REAL-TIME UPDATES & ANIMATIONS

When any input changes anywhere in the app:

1. DETECT CHANGE:
   - Listen to all input fields across all tabs
   - Debounce updates (150ms) to avoid excessive recalculation
   - Update all affected values in Live Receipt

2. HIGHLIGHT AFFECTED VALUES:
   When a value updates, animate it:
   
   BEFORE:
   Annual encounters                    100,000
   
   DURING UPDATE (when user types "150000"):
   Annual encounters                    150,000
   ^^^^^^^^^^^^^^^^^ Brief highlight with #FEF3C7 background
   
   AFTER (300ms later):
   Annual encounters                    150,000
   ^^^^^^^^^^^^^^^^^ Fade back to normal

3. CASCADE EFFECT:
   If one value affects others, highlight them in sequence:
   
   User changes: Annual encounters 100,000 → 150,000
   
   Step 1 (0ms): Highlight "Annual encounters" 
   Step 2 (100ms): Highlight "Eligible encounters" (calculated from annual)
   Step 3 (200ms): Highlight "Hours returned (gross)" 
   Step 4 (300ms): Highlight affected driver values (Patient Access, etc.)
   Step 5 (400ms): Highlight "Total Benefit" and "Net Annual Gain"

4. NUMBER TRANSITIONS:
   - Use CSS transitions for smooth number changes
   - Duration: 200ms ease-out
   - No counter animations (just smooth swap)
   - Keep tabular number alignment during transition

5. VISUAL FEEDBACK:
   - Highlight color: #FEF3C7 (light yellow/orange)
   - Fade from highlight to normal: 300ms ease-out
   - Pulse on major values (Net Annual Gain): Subtle scale 1.0 → 1.02 → 1.0 (200ms)

ANIMATION CODE PATTERN:
```css
.receipt-value-updated {
  animation: highlight-value 300ms ease-out;
}

@keyframes highlight-value {
  0% { background-color: transparent; }
  30% { background-color: #FEF3C7; }
  100% { background-color: transparent; }
}

.receipt-major-value-updated {
  animation: pulse-value 200ms ease-out;
}

@keyframes pulse-value {
  0% { transform: scale(1); }
  50% { transform: scale(1.02); }
  100% { transform: scale(1); }
}
