# FINAL REPLIT SPEC — All Domain Updates

## What This Document Is

This is the complete, final specification for updating all four domain screens in the Ambient AI assessment path. It covers every level, every input, every formula, every output message, and every edge case. Paste this into Replit and have the AI implement these changes.

The design principle: a senior executive should be able to sit with you for 30-45 minutes, go through all four domains, and walk away understanding exactly where their organization stands — and what they're not doing. Every screen should feel like a conversation, not a form.

---

## GLOBAL RULES (apply to all domains)

### Input Rules
- NO input should ever have a pre-filled default value on sliders or number fields (exception: revenue per visit and provider rate in baseline advanced settings)
- Every empty input shows "—" or "Not yet measured" in the impact card, NEVER "$0"
- All benchmark text uses this pattern: *"Organizations at this stage have reported [X]. Based on aggregated deployment experience."* — never "Abridge customers report"
- Every formula is shown in small italic text below the output
- Every rate assumption ($75/hr, $150/hr, etc.) is labeled explicitly in the formula display

### Impact Card Rules
- Always show "Estimates based on your inputs. Individual results vary." at the bottom
- When inputs are missing, show what to enter: "Enter [X] to calculate impact"
- Never show $0 for missing data — show "—" or "Not yet measured"
- Hours-based outputs show hours as the headline, dollar equivalents in supporting text only (Workforce L1 and L2)

### Working Assumptions (used across domains)
```
FTE_HOURS = 2,080
WORKING_DAYS = 230  ← CHANGED FROM 250 (more accurate for clinical providers)
WORKING_WEEKS = 52
ABSTRACTION_RATE = 75  // $/hr for compliance/quality work
CMS_CONVERSION_FACTOR = 36.04  // for wRVU calculations
```

## IMPLEMENTATION NOTES

1. **Capacity L1 and L2 share the time saved input.** If entered at L1 and user switches to L2, preserve the value. If user goes directly to L2, show the input. At L3 and L4, this input does NOT appear.

2. **Capacity L3 has an optional "providers with redesigned schedules" field.** Defaults to total provider count from baseline. User can override downward. Formula uses this number instead of total providers.

3. **Revenue L3 denial rate is qualitative only.** Shows the percentage, does NOT attempt dollar conversion. Explains how the user can calculate it themselves.

4. **Workforce L2 uses 230 working days** (not 250). This is more accurate for clinical providers accounting for PTO, CME, and holidays.

5. **Risk L2 radio buttons have NO default selection.** User must choose before impact card shows content.

6. **Risk L3 hours input is labeled "optional"** and the domain works with just checkboxes.

7. **All inputs persist** when navigating between domains. If user goes back to Capacity after completing Revenue, all Capacity inputs remain.

8. **All level selections persist** per domain across navigation.

9. **Revenue L3 CMS conversion factor** is adjustable in baseline advanced settings. Default $36.04. Shown in formula when wRVU is selected.
