CRITICAL: The quarterly inputs are the single source of truth that drives EVERYTHING:


The chart updates in real-time as quarterly values change. Each quarter on the x-axis uses that quarter's providers × utilization to calculate actively documenting providers, applies value driver onset delays, and plots the stacked value area. The investment dashed line uses that quarter's cost.
Monthly cash flows for IRR and Payback are derived from quarterly inputs — each quarter's values apply to its 3 months. If Q1'26 has 250 providers at 30% utilization and $115/mo, then months 1-3 each have: cost = 250 × $115 = $28,750, value = 250 × 30% × per-provider monthly value with applicable delays.
The 3-Year Financial Summary table stays annual — it sums Q1-Q4 for each year. The quarterly data feeds monthly calcs that roll up.
All metrics recalculate (ROI, Value-to-Cost, IRR, Payback) based on the quarterly schedule.
The payback marker on the chart moves dynamically — if the user models a faster rollout (more providers in early quarters, higher utilization), payback moves earlier. Slower rollout pushes it later.
