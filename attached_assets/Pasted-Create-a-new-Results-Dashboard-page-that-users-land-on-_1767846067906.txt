In the Summary View tab, build the headline results section at the top.

LAYOUT:
Create a prominent card/section that displays:

Header:
"YOUR ROI MODEL"
Subtitle line 1: "Based on [X] providers, [Y] Abridge-documented encounters"
Subtitle line 2: "[Care Setting] care setting"

(Pull X, Y, and Care Setting from the model data)

Main Metrics Section:
Display two large metrics side-by-side:

Left metric:
- Large dollar amount: NET ANNUAL GAIN
- Calculate as: (Total Annual Benefit - Annual Investment)
- Format with $ and commas (e.g., $343,100)
- Label below in smaller text: "Net Annual Gain"

Right metric:
- Large number with "x": RETURN ON INVESTMENT  
- Calculate as: (Total Annual Benefit / Annual Investment)
- Format as decimal with 2 places (e.g., 6.96x)
- Label below in smaller text: "Return on Investment"

Below the main metrics, show:
"Total Annual Benefit: $[calculated]"
"Annual Investment: $[calculated]"

STYLE:
- Large card with subtle shadow
- Generous padding
- Main metrics in very large, bold font
- Use accent/brand color for the dollar amounts
- Clean, spacious layout
- Match the card styling from Value Blueprint section

CALCULATIONS:
- Total Annual Benefit = sum of all selected driver values
- Annual Investment = from Tab 3 (providers × cost per provider × 12)
- Net Annual Gain = Total Benefit - Investment
- ROI = Total Benefit / Investment
