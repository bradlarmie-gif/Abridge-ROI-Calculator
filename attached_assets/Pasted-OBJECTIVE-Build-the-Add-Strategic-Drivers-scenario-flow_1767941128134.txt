PART 11: CALCULATION LOGIC

For each selected driver, calculate value using baseline model inputs:
- Use same formulas as Detailed Breakdown
- Use baseline encounters, utilization, etc.
- Apply any user adjustments from "ADJUST FOR YOUR ORGANIZATION"

Real-time update behavior:
- When driver checkbox changes: Recalculate totals
- When adjustment slider changes: Recalculate that driver + totals
- Debounce by 300ms
- Highlight changed values in preview (200ms fade)

Driver calculation formulas (reference):

HCC Capture:
- unique_patients = eligible_encounters / 2.5
- ma_patients = unique_patients × ma_population %
- conditions_missed = ma_patients × 2.5 × 0.30
- conditions_recaptured = conditions_missed × recapture_rate
- raf_increase = conditions_recaptured × 0.25 / ma_patients
- value = ma_patients × benchmark_pmpm × 12 × raf_increase

Denial Reduction:
- total_revenue = eligible_encounters × revenue_per_visit
- revenue_denied = total_revenue × denial_rate
- doc_denials = revenue_denied × 0.30
- value = doc_denials × prevention_rate

Overtime Cost:
- total_hours = (minutes_saved × eligible_encounters) / 60
- premium_hours = total_hours × after_hours_reduction %
- value = premium_hours × blended_premium_rate
