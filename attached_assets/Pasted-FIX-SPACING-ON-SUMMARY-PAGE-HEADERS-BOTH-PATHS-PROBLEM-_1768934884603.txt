FIX SPACING ON SUMMARY PAGE HEADERS - BOTH PATHS

## PROBLEM
The header sections on both Human Scribes and Ambient AI summaries
feel cramped. Text is too tight together. Needs more breathing room.

## HUMAN SCRIBES SUMMARY HEADER

Current structure:
- "THE REAL QUESTION" (label)
- "What would you do with $228,100/year?" (headline)
- Subtitle about scribe program

Spacing fixes:
1. Gap between label and headline: increase to 16px
2. Gap between headline and divider line: increase to 24px
3. Add a subtle centered divider line (60px wide, 2px tall, light gray)
4. Gap between divider and subtitle: 16px

GENERAL PRINCIPLES

When in doubt, add more vertical space
Headlines need room to breathe
Big numbers should feel important, not cramped
Use consistent spacing increments (8px, 16px, 24px, 32px, 48px)
Muted text (gray) should have slightly more space around it
