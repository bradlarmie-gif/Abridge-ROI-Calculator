Build a premium PDF export for the Scribe Program Analysis. The design should feel like McKinsey meets Stripe meets Apple — data-rich, clean typography, confident, with minimal but purposeful white space.

## TECHNICAL APPROACH

Use a library that can generate styled PDFs. Options:
1. **react-pdf** (@react-pdf/renderer) — Best for complex layouts
2. **html2canvas + jsPDF** — Simpler, captures the page as-is
3. **Custom print stylesheet** — Uses browser print, style with @media print

I recommend **@react-pdf/renderer** for maximum control over the design.

// Export function
export const generateScribePDF = async (data) => {
  const blob = await pdf(<ScribePDFDocument data={data} />).toBlob();
  saveAs(blob, `scribe-program-analysis-${new Date().toISOString().split('T')[0]}.pdf`);
};

export default ScribePDFDocument;

jsxCopyimport { generateScribePDF } from './ScribePDFExport';

// In your component
const handleExport = async () => {
  const exportData = {
    scribeCount,
    scribeSalary,
    scribeHoursPerWeek,
    scribeCostPerHour,
    providersWithScribes,
    totalProviders,
    encounters,
    totalScribeCost,
    coveragePercent,
    unsupportedProviders,
    costPerCoveredProvider,
    scribesNeededForFull,
    fullScribeCost,
    additionalCostToScale: fullScribeCost - totalScribeCost,
    scribeRatio,
    documentationHours,
    pajamaTimeHours,
    hoursPerUnsupportedProvider: Math.round(documentationHours / unsupportedProviders),
    encountersPerProvider: Math.round(encounters / totalProviders),
  };
  
  await generateScribePDF(exportData);
};

// Button
<button onClick={handleExport} className="export-btn">
  <span className="icon">📄</span>
  Export as PDF
</button>
