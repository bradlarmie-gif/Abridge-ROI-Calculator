1. Fix IRR Cash Flow Structure (CRITICAL — must be mathematically correct)
The current IRR puts all investment in Period 0 then shows only value inflows. This is wrong — Abridge is a subscription, not a capital expenditure.
Correct implementation:
For each month (1 through 36):
  monthly_cost = licensed_providers_that_month × price_per_provider_per_month
  monthly_value = actively_documenting_providers_that_month × per_provider_monthly_value (based on utilization, time saved, value drivers, onset delays)
  monthly_net_cash_flow[month] = monthly_value - monthly_cost

Month 0 cash flow = implementation fee only (if any). If no impl fee, Month 0 = $0.
Solve for monthly rate r where: Σ (monthly_net_cash_flow[t] / (1+r)^t) = 0 for t = 0 to 36
Annualize: Annual IRR = (1 + r)^12 - 1
Keep Newton-Raphson with bisection fallback. Use MIRR only if cash flows alternate sign multiple times.
This will produce a lower, more believable IRR because it properly reflects that costs are spread over time, not front-loaded.
Update methodology text to:
"IRR: Solved on monthly net cash flows (monthly value minus monthly subscription cost) over the contract term. Accounts for implementation ramp, utilization growth, and provider expansion timing. Annualized from the monthly rate."
Remove the current language about "Period 0 represents total investment."
