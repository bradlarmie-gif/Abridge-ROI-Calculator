CALCULATIONS:

// Patient Days
patientDaysPerYear = staffedBeds * 365 * (occupancyRate / 100)

// Annual Shifts (each nurse works ~260 shifts/year)
annualShifts = nurseFTEs * 260

// Base documentation time (assume 2 hours/shift average)
baseDocTimePerShift = 2 // hours
totalAnnualDocTime = annualShifts * baseDocTimePerShift

// Eligible documentation time (what Abridge touches)
eligibleDocTime = totalAnnualDocTime * (impactRate / 100)

// This becomes the input for Time Savings page

WHY THIS IS BETTER

Honest about complexity — Nursing isn't like outpatient where utilization is straightforward
Accounts for partial coverage — Abridge doesn't touch all flowsheets, and the user knows we know that
Lower, more realistic defaults — 25/40/55% is more believable than 40/55/60%
Single input, explained well — We don't make them guess at adoption AND coverage separately
Better output metric — "Eligible Documentation Time" is more meaningful than "Eligible Shifts"
