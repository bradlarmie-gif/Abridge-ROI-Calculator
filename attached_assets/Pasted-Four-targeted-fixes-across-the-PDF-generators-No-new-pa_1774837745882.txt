  const formatCurrency = (value: number): string => {
    if (Math.abs(value) >= 1000000) return `$${(value / 1000000).toFixed(1)}M`;
    if (Math.abs(value) >= 1000) return `$${Math.round(value / 1000).toLocaleString()}K`;
    return `$${value.toLocaleString()}`;
  };

  FIX 3 — Outpatient copy: cut "conservative" repetition

  File: client/src/lib/outpatient-pdf-generator.tsx

  The word "conservative" appears 20+ times. It stops meaning anything by repetition. Apply these rules:

  1. Keep it in exactly two places:
    - The TransparencyPage "Methodology Statement" callout — this is where it belongs as a principle statement
    - One instance in a driver calibration note where the specific rate is cited (e.g., "our 3% is deliberately modest vs. the 8-15% range in published studies")
  2. Remove it everywhere else. Specifically:
    - In calibration notes, replace "Conservative estimate" as a standalone label with the actual number and its rationale. Example: instead of "Conservative estimate: 15% realization", write "15%
  realization — accounts for scheduling friction and demand variability"
    - Remove any sentence that is purely "We use conservative assumptions" or "These are conservative projections" without adding new information
    - Remove standalone uses of "conservative" as an adjective in step box explanations where the surrounding copy already explains the reasoning
  3. Do not change any numbers — only the copy that describes them. The realization rates, inputs, and formulas stay exactly the same.
