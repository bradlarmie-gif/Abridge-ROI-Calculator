I need to completely redesign the Summary page with a "Pilot → Expand → Full Scale" journey visualization. Here's the full specification:

## PAGE STRUCTURE

The summary page should have these sections in order:

1. HEADER
- Back to Model Builder link
- Breadcrumb showing: Setting | Units | Net Value | ROI
- Edit Model button
- Export & Share button

2. HERO METRICS
- Three big numbers: Net Annual Value (green), ROI Multiple, Payback Period
- Subtext showing Total Annual Value and Annual Investment

3. YOUR JOURNEY WITH ABRIDGE (Main Feature)
- Title: "Your Journey with Abridge"
- Subtitle: "Start with a pilot. Prove the value. Scale across your organization."
- Bar chart showing 3 stages: Pilot (coral), Expand (gray), Full Scale (green)
- Dashed lines connecting the bars
- Three cards below showing details for each stage
- Key Insight callout explaining ROI improves at scale
- Interactive inputs to customize Full Scale opportunity

4. VALUE BREAKDOWN
- Two category cards: Labor & Efficiency, Revenue & Quality
- Visual percentage bar

5. INVESTMENT DETAILS
- Your Configuration card
- Multi-Year Projection table

6. KEY ASSUMPTIONS
- Bullet list

7. ACTIONS
- Add Another Driver button
- Export options

## JOURNEY CHART DETAILS

The chart should show three bars:
- PILOT (coral/orange #f97316): Current state, "You are here"
- EXPAND (gray #94a3b8): Next phase, ~3x pilot
- FULL SCALE (green #059669): Full opportunity, user-customizable

Each stage card shows:
- Stage name and icon
- Number of providers/beds
- Utilization percentage
- Number of encounters
- Value, Investment, Net, ROI

The Full Scale stage should be editable with two inputs:
- Total providers/beds slider
- Expected utilization slider

## CALCULATIONS

For each stage:
- encounters = units × encounters_per_unit × utilization_rate
- value = encounters × value_per_encounter (derived from pilot data)
- investment = units × price_per_unit × 12
- net = value - investment
- roi = value / investment

Pilot values come from the model builder.
Expand = pilot × 3 providers, 65% utilization
Full Scale = user input providers, user input utilization (default 75%)

  utilizationRate

  const [fullScaleUtilization, setFullScaleUtilization] = useState(75);
  
  // ============ DERIVED CALCULATIONS ============
  
  // Value per encounter (derived from pilot)
  const pilotEncounters = totalEncounters * utilizationRate;
  const valuePerEncounter = totalAnnualValue / pilotEncounters;
  const encountersPerUnit = totalEncounters / currentUnits;
  
  // Pilot stage (current state)
  const pilot = useMemo(() => ({
    stage: 'pilot',
    label: 'PILOT',
    sublabel: 'You are here',
    icon: '📍',
    units: currentUnits,
    utilization: Math.round(utilizationRate * 100),
    encounters: Math.round(pilotEncounters),
    value: totalAnnualValue,
    investment: annualInvestment,
    net: totalAnnualValue - annualInvestment,
    roi: (totalAnnualValue / annualInvestment).toFixed(1)
  }), [currentUnits, utilizationRate, pilotEncounters, totalAnnualValue, annualInvestment]);
  
  // Expand stage (~3x pilot, 65% utilization)
  const expand = useMemo(() => {
    const units = Math.round(currentUnits * 3);
    const utilization = 0.65;
    const encounters = units * encountersPerUnit * utilization;
    const value = encounters * valuePerEncounter;
    const investment = units * pricePerUnit * 12;
    return {
      stage: 'expand',
      label: 'EXPAND',
      sublabel: 'Next phase',
      icon: '📈',
      units,
      utilization: 65,
      encounters: Math.round(encounters),
      value: Math.round(value),
      investment: Math.round(investment),
      net: Math.round(value - investment),
      roi: (value / investment).toFixed(1)

  // Full Scale stage (user customizable)

    const utilization = fullScaleUtilization / 100;

    const value = encounters * valuePerEncounter;
    const investment = units * pricePerUnit * 12;
    return {
      stage: 'fullScale',
      label: 'FULL SCALE',
      sublabel: 'Your opportunity',
      icon: '🚀',

      utilization: fullScaleUtilization,

      value: Math.round(value),
      investment: Math.round(investment),
      net: Math.round(value - investment),
      roi: (value / investment).toFixed(1)
    };
  }, [fullScaleUnits, fullScaleUtilization, encountersPerUnit, valuePerEncounter, pricePerUnit]);
  
  // Chart data

    { name: 'Pilot', value: pilot.value, stage: 'pilot' },
    { name: 'Expand', value: expand.value, stage: 'expand' },
    { name: 'Full Scale', value: fullScale.value, stage: 'fullScale' }

  // Hero metrics
  const netValue = pilot.net;
  const roiMultiple = pilot.roi;
  const paybackMonths = Math.round((annualInvestment / totalAnnualValue) * 12);

  const laborDrivers = valueBreakdown.filter(d => d.category === 'labor');
  const revenueDrivers = valueBreakdown.filter(d => d.category === 'revenue');
  const laborValue = laborDrivers.reduce((sum, d) => sum + d.value, 0);
  const revenueValue = revenueDrivers.reduce((sum, d) => sum + d.value, 0);
  const laborPercent = Math.round((laborValue / totalAnnualValue) * 100);
  const revenuePercent = 100 - laborPercent;
  
  // Multi-year projection (10% growth)

  const year2 = Math.round(totalAnnualValue * 1.10);
  const year3 = Math.round(totalAnnualValue * 1.21);
  const threeYearValue = year1 + year2 + year3;
  const threeYearCost = annualInvestment * 3;
  const threeYearNet = threeYearValue - threeYearCost;
  
  // Expansion potential

            <span className="divider">│</span>

            <span className="divider">│</span>
            <span className="highlight">${netValue.toLocaleString()} net value</span>
            <span className="divider">│</span>
            <span className="highlight">{roiMultiple}x ROI</span>
          </div>
        </div>
        <div className="header-actions">
          <button className="btn-secondary">✏️ Edit Model</button>

        </div>

          </div>

            <div className="metric-value">{roiMultiple}x</div>
