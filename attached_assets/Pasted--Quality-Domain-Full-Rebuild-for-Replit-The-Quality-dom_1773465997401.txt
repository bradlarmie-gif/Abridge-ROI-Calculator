# Quality Domain — Full Rebuild for Replit

The Quality domain is currently trying to do too much. It has six downstream workflows at Level 3 each with before/after inputs, HCC calculations with indefensible assumptions, and a Level 4 that's just governance checkboxes and a dollar input. Rebuild it to be focused, strategic, and completable in 5-8 minutes of conversation.

The core story: ambient documentation creates structured, complete clinical notes at scale. That's a data asset. Quality measures whether the organization is building on that asset or just letting it sit in the EHR.

Keep the same UX patterns, card treatments, sidebar formula panel, and brand styling. Change the content, inputs, and calculations.

## Level 1: Notes Improving

**Card text:**
```
Notes Improving
Documentation quality has improved. No one has
measured how or connected it downstream.
```

**Description when selected:**
"Documentation quality has improved. Downstream teams have not yet been engaged."

**Inputs:**
```
Have any downstream teams reviewed documentation
changes from ambient?
○ Not yet
○ Starting informally
○ One team is formally in
```

That's it. No chart completion rate input. No coding accuracy percentage. Those are Level 2 concerns. Level 1 is simply: notes are better, nobody downstream has looked.

**Remove from Level 1:**
- Remove "Current chart completion rate" input
- Remove "Average coding accuracy" input
- Remove ALL dollar calculations at Level 1
- Remove any denial exposure, HCC exposure, or quality gap calculations

**Estimated Impact card:**
```
ESTIMATED IMPACT

[documentedEncounters] encounters with improved
documentation.

Downstream connection not yet started. The value
of improved documentation depends on whether
coding, quality reporting, compliance, and other
teams can see and use the improvement.

Level 2 establishes systematic quality tracking.

Estimates based on your inputs. Individual results vary.
```

No dollars. The insight is that nobody downstream is using the improvement yet.

## Level 3: Downstream Connected

**Card text:**
```
Downstream Connected
Documentation quality improvements are connected
to at least one downstream program or workflow.
```

**Description when selected:**
"At least one downstream workflow shows measurable improvement from documentation quality."

**Inputs:**
```
Which downstream areas have been connected to
documentation quality improvements?

☐ CDI — fewer queries, faster turnaround, or
  improved capture rates
☐ Coding accuracy — specificity improvements
  or denial reduction
☐ Quality measures — HEDIS, MIPS, or Stars gap
  closure improved
☐ Prior authorization — documentation supporting
  faster or higher approval rates
☐ Chart abstraction — less manual effort for
  registries, research, or reporting
☐ Risk adjustment — HCC capture or RAF accuracy
  improved for VBC populations

For connected areas, has the impact been measured?
○ Qualitatively — we can see improvement but
  haven't quantified it
○ Partially — some areas have before/after data
○ Yes — we have measured data for connected workflows
```

**Remove the entire before/after input matrix.** Currently Level 3 opens sub-inputs for each checked workflow (CDI queries before/after, denial rate before/after, prior auth before/after, quality gaps per month, abstraction hours, RAF score change, members in VBC, capitation rate). This is too much for a 30-minute session. An executive cannot fill in before/after data for six different workflows.

Replace with ONE optional summary input:

```
If you can estimate the combined annual value of
documentation quality improvements across your
connected workflows, enter it here. (optional)

$ [___]

This could include CDI efficiency gains, coding
accuracy improvements, quality measure incentives
captured, abstraction time saved, or other
measurable downstream value.

☐ Don't have a combined number yet
```

**Estimated Impact card:**

If checkboxes + no dollar value:
```
ESTIMATED IMPACT

[checkedCount] downstream area(s) connected

Documentation quality is driving improvement
across [checkedCount] area(s):
[list of checked items]

[If "Qualitatively":] Impact is visible but not
yet quantified.
[If "Partially":] Some areas have measured data.
[If "Yes":] Measured data is available.

Not yet connected:
[list of unchecked items]

Estimates based on your inputs. Individual results vary.
```

If dollar value entered:
```
ESTIMATED IMPACT

$[annualValue] in downstream quality value
[checkedCount] area(s) connected

Documentation quality is driving $[annualValue]
in annual value across [checkedCount] area(s):
[list of checked items]

Not yet connected:
[list of unchecked items]

Based on your organization's estimate.
Estimates based on your inputs. Individual results vary.
```

**Why this is better:** The checkboxes show breadth (how many downstream areas are connected). The measurement question shows depth (how rigorously). The optional dollar input lets organizations that have a number share it without forcing organizations that don't to guess. The "not yet connected" list creates the gap visualization. Clean, fast, conversational.

## What Gets Removed from Quality Entirely

1. **All the before/after input matrices at Level 3.** CDI queries before/after, denial rate before/after, prior auth rates, quality gaps per month with $100/gap assumption, abstraction hours, RAF score change, members in VBC, capitation rate. ALL of it. Replaced with checkboxes for what's connected + one optional dollar input.

2. **The $25/CDI query hidden assumption.** Gone. No per-query calculations.

3. **The $100/quality gap assumption.** Gone. No per-gap calculations.

4. **The HCC calculation from Level 1.** The $200/member × VBC% producing massive numbers. Gone from Quality Level 1. If HCC capture matters, it's a checkbox at Level 3 ("Risk adjustment — HCC capture improved") and a strategic checkbox at Level 4 ("Value-based care — documentation supports risk stratification"). Not a formula.

5. **The denial exposure calculation from Level 1.** Same as Revenue — we removed dollar calculations from Level 1 there too. Consistency.

6. **"Average days to chart closure" at Level 2.** Too granular.

7. **"Compliance audit pass rate" at Level 2.** Too granular.

8. **"What % of reviewed charts have documentation gaps" at Level 2.** Asking a percentage that most executives won't know in a live conversation.

## The Clean Progression

```
Level 1: Notes Improving
"Documentation is better. Nobody downstream has looked."
Input: engagement status (radio)
Output: encounter volume, no dollars

Level 2: Actively Monitored
"We're measuring documentation quality attributes."
Input: tracking method + what attributes (checkboxes)
Output: X of 5 dimensions tracked, no dollars

Level 3: Downstream Connected
"Documentation quality is improving downstream workflows."
Input: which areas connected (checkboxes) + optional $
Output: X areas connected + dollar value if entered

Level 4: Documentation as a Strategic Asset
"Documentation quality informs organizational strategy."
Input: strategic areas (checkboxes) + optional $
Output: X strategic areas + dollar value if entered
```

Dollars only appear at Level 3 and 4 — and only if the organization enters them. Levels 1 and 2 are qualitative. This matches the pattern across all four domains: early levels are about awareness and measurement, higher levels are about action and strategy.
