Design Principles to Follow

Progressive Disclosure: Only show what's relevant at each step
Contextual Intelligence: Show hints/benchmarks that help them understand if their inputs are realistic
No Aggressive Sales Language: Let the numbers speak for themselves
Honest About Time: The realistic timeline modal builds trust
Visual Hierarchy: The big number (switching opportunity) should be the clear focal point
Always Show the Math: Every number should have a tooltip or caption explaining how it was calculated
Stripe-like Polish: Clean, minimal, lots of whitespace, subtle animations on state changes


Implementation Notes

State Management: All inputs should persist across steps (use React context or similar)
Real-time Calculations: The "Calculated Summary" boxes should update as inputs change
Validation: Gentle validation - highlight unrealistic inputs but don't block progress
Mobile Responsive: The flow should work on tablets (common in healthcare settings)
Export: The final opportunity view should be exportable as a PDF
