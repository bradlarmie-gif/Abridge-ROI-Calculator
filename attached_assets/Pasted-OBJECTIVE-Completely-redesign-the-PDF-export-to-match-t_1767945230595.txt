OBJECTIVE:
Completely redesign the PDF export to match the quality and professionalism of the in-app experience. Transform it from a data dump into an executive-ready business case document. Support both baseline model export AND scenario comparison export.

CRITICAL RULES:
- Match Abridge brand colors and typography
- Professional multi-page layout (not cramped single page)
- Clear visual hierarchy with generous white space
- Support THREE export types: Baseline, Single Scenario, Scenario Comparison
- Include step-by-step math for transparency
- Print-optimized (grayscale-friendly, proper margins)
- Generate filename dynamically based on content

PART 1: THREE EXPORT TYPES

TYPE 1: BASELINE MODEL EXPORT
Triggered from: Summary View → Export tab
Content: Current baseline model only
Use case: Initial proposal, board presentation

TYPE 2: SINGLE SCENARIO EXPORT
Triggered from: Scenario card → [Export] action
Content: Scenario details + comparison to baseline
Use case: Specific expansion proposal (e.g., "Add ED")

TYPE 3: SCENARIO COMPARISON EXPORT
Triggered from: Comparison View → [Export Comparison]
Content: Side-by-side comparison of 2-3 scenarios
Use case: Decision support, evaluating options

Each type has different layout but consistent styling.

PART 5: TECHNICAL IMPLEMENTATION

PDF Generation Library:
Use react-pdf or jsPDF with proper styling support

Page Structure:
- Page size: Letter (8.5" × 11")
- Margins: 1 inch all sides
- Print-safe colors (test grayscale rendering)
- Page numbers bottom right
- Header on each page (small, gray)

Typography:
- Use system fonts for reliability: -apple-system, BlinkMacSystemFont, "Segoe UI"
- Or embed: Inter, Open Sans (if supported by PDF library)
- Font sizes: 10px-32px scale
- Line-height: 1.4-1.6 for readability
- Generous spacing between sections

Colors:
- Keep consistent with app:
  - #E8532F (Abridge orange)
  - #111827 (black text)
  - #6B7280 (gray text)
  - #059669 (green for values)
  - #F9FAFB (light gray backgrounds)
- Ensure grayscale-friendly (no reliance on color alone)

Branding:
- Abridge geometric pattern on cover (2-3% opacity)
- NO logo needed (pattern provides brand)
- abridge.com/roi footer on each page
- Professional, not corporate

Generated Filenames:
- Baseline: "Abridge_ROI_Model_[OrgName]_[Date].pdf"
- Scenario: "Abridge_ROI_[ScenarioName]_[OrgName]_[Date].pdf"
- Comparison: "Abridge_ROI_Comparison_[OrgName]_[Date].pdf"

Export Triggers:
1. Summary View → Export tab → "Generate PDF" button
2. Scenario card → [Export] action → Generate scenario PDF
3. Comparison View → "Export Comparison" button → Generate comparison PDF
