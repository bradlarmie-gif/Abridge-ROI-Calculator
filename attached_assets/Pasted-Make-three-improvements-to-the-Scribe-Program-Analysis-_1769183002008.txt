The Ambient AI Curve Shape
The ambient AI line should show a curve that:

Starts relatively close to the scribe line at low coverage
Flattens as coverage increases (economies of scale)
Creates a widening gap compared to the linear scribe line

Use a logarithmic or square-root curve shape:
javascriptCopy// Scribe cost at coverage X%
const scribeCostAtCoverage = (coverage) => {
  return (coverage / 100) * fullScribeCost;
};

// Ambient AI curve shape (NO actual dollar values — just relative shape)
// This is for visualization only — shows the per-provider model flattening
const ambientAIShape = (coverage) => {
  // Use square root curve to show diminishing per-unit cost
  // Scale it relative to scribe cost but with significant divergence
  const scaleFactor = 0.4; // Ambient AI ends up at ~40% of scribe cost at full coverage
  const curveShape = Math.sqrt(coverage / 100); // Flattening curve
  return curveShape * fullScribeCost * scaleFactor;
};
