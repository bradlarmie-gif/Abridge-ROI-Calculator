 Philosophy

  Financial value from Abridge comes from three defensible categories only:

  1. Billing Capture — metrics that directly affect what gets billed
  - wRVU per encounter lift → wRVU delta × adopted encounters × conversion factor × realization rate
  - E/M level improvement → E/M delta × encounters × average E/M level dollar value
  - CMI improvement (inpatient) → CMI delta × discharges × DRG base rate

  2. Revenue Recovery — metrics that recover revenue that would have been lost
  - LWBS rate reduction (ED) → LWBS delta (%) × total ED visits × average ED visit revenue
  - Denial rate reduction → denial delta (per 100) / 100 × encounters × average denial cost per case

  3. Actual Cost Reduction — real payroll and turnover savings, NOT theoretical capacity
  - After-hours / work outside hours reduction → hours eliminated per week × OT premium rate × FTE count × 52 weeks
    - Use OT premium (1.5× base), not full hourly rate. Default OT premium: $75/hr. User-adjustable.
    - This is payroll cost avoided, not "time freed up"
  - Burnout / Likelihood to Stay signal → if these metrics are entered and improved, show turnover avoidance range using published MGMA benchmarks: $50K–$150K per physician, $30K–$70K per APP/NP

  What NOT to include:
  - time saved × hourly rate = value — never
  - Capacity expansion revenue from freed time — this belongs on Page 5 (opportunity), not Page 4
  - Any metric that isn't in one of the three categories above

  ---
  Hero Rules

  - Never show $0. If no financial metrics are entered, hide the hero entirely. Show a soft prompt: "Add wRVU, E/M, CMI, LWBS, or after-hours data on the previous page to see estimated financial impact."
  - If only Billing Capture data exists → show billing capture range as hero
  - If only Cost Reduction data exists → show cost reduction range as hero
  - If multiple categories have data → sum all categories, show combined range
  - Low end uses 50% attribution / 70% realization. High end uses 75% attribution / 90% realization.
  - Animate from $0 to final value using the useCountUp hook (requestAnimationFrame, easeOutCubic, 1.2s, 300ms delay) — create client/src/hooks/useCountUp.ts if it doesn't exist

  Data Wiring

  Read data from state (the MeasureState prop). Key fields:

  // Billing Capture
  const wrvuDelta = state.documentationQuality.wrvuWith - state.documentationQuality.wrvuWithout;
  const emDelta = state.documentationQuality.emLevelWith - state.documentationQuality.emLevelWithout;
  const adoptedEncounters = state.deployment.totalEncounters * (state.deployment.utilizationRate / 100);
  const annualFactor = 12 / Math.max(getMonthsFromGoLive(state.goLiveDate, state.deployment.monthsOnAbridge), 1);

  // Cost Reduction — after hours
  const afterHoursWithout = state.timeEfficiency.workOutsideWithout;  // hrs/day
  const afterHoursWith = state.timeEfficiency.workOutsideWith;
  const afterHoursDelta = afterHoursWithout - afterHoursWith;  // positive = reduction

  const settingData = state.settingData?.[state.careSetting || 'outpatient'] || {};

  const lwbsAfter = settingData.lwbsRate_after ?? 0;
  const lwbsDelta = lwbsBefore - lwbsAfter;  // positive = improvement

  // CMI — inpatient
  const cmiBefore = settingData.cmi_before ?? 0;
  const cmiAfter = settingData.cmi_after ?? 0;
  const cmiDelta = cmiAfter - cmiBefore;

  ---
  useCountUp Hook

  If client/src/hooks/useCountUp.ts doesn't exist, create it:

  import { useState, useEffect, useRef } from 'react';

  function easeOutCubic(t: number): number {
    return 1 - Math.pow(1 - t, 3);
  }

  export function useCountUp(target: number, duration = 1200, delay = 300): number {
    const [current, setCurrent] = useState(0);
    const rafRef = useRef<number>(0);
    const startRef = useRef<number | null>(null);

    useEffect(() => {
      if (target === 0) { setCurrent(0); return; }
      const timeout = setTimeout(() => {
        const animate = (timestamp: number) => {
          if (!startRef.current) startRef.current = timestamp;
          const elapsed = timestamp - startRef.current;
          const progress = Math.min(elapsed / duration, 1);
          setCurrent(Math.round(target * easeOutCubic(progress)));
          if (progress < 1) rafRef.current = requestAnimationFrame(animate);
        };
        rafRef.current = requestAnimationFrame(animate);
      }, delay);
      return () => { clearTimeout(timeout); cancelAnimationFrame(rafRef.current); startRef.current = null; };
    }, [target, duration, delay]);

    return current;
  }

  Verification

  1. Enter only wRVU before/after → billing capture row appears, hero counts up to non-zero range, no other rows render
  2. Enter only after-hours before/after → cost reduction row appears, hero shows OT savings range
  3. Enter both → hero combines both ranges, two rows visible
  4. Enter nothing → hero hidden entirely, soft prompt visible
  5. Move realization slider → all numbers update instantly, no page jump
  6. ED setting → revenue recovery row visible when LWBS entered, "ED revenue per visit" field appears in sensitivity panel
  7. Inpatient setting → CMI row shows inside billing capture, "DRG base rate" field in sensitivity
  8. "Also Real. Not Quantified." renders below calculated rows regardless of data state
  9. No white cards anywhere — all section backgrounds are bg-[#F5F0EB]
  10. No time × hourly rate calculation anywhere in the file
