NURSING PATH — COMPREHENSIVE REPLIT PROMPT

OVERVIEW
This prompt covers the complete Nursing Explore path with:

Staffed beds-based baseline (Page 1)
Shift-based time savings (Page 2)
Labor-focused time value drivers (Page 3)
Care quality potential drivers (Page 4)
Investment (Page 5)
Summary with Connected Value section (Page 6)

The Nursing path requires a fundamentally different approach because nurses don't bill. All value flows through labor economics (OT, retention, agency) and care quality enablement (HAPIs, falls, HCAHPS).

Calculations:
javascriptCopy// Patient Days
patientDaysPerYear = staffedBeds * 365 * (occupancyRate / 100)

// Annual Shifts (assuming 3 shifts per day coverage)
// Each nurse works ~260 shifts/year (5 days × 52 weeks)
// But we need to cover 365 days × 3 shifts = 1,095 shift-slots per bed
// Simpler: Nurse FTEs × shifts per nurse per year
annualShifts = nurseFTEs * 260  // Conservative estimate

// Eligible Shifts
eligibleShifts = annualShifts * (utilizationRate / 100)

OT Reduction Math:
javascriptCopy// Current annual OT
annualOTHours = nurseFTEs * otHoursPerWeek * 52

// OT hours reduced (based on time saved, not current OT)
otHoursReduced = hoursSaved * (timeToOTConversion / 100)

// Cap it: Can't reduce more OT than exists
otHoursReduced = Math.min(otHoursReduced, annualOTHours)

// Savings
otSavings = otHoursReduced * otHourlyRate
