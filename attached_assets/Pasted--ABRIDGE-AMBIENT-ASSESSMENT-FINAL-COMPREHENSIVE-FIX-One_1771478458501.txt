# ABRIDGE AMBIENT ASSESSMENT — FINAL COMPREHENSIVE FIX
## One prompt. Every screen. Do not skip anything.

---

## THE STANDARD

Look at the home screen of this app. Three cards. Beige backgrounds. Clean red CTAs. Diagonal watermark. Premium spacing. That is the visual standard every screen in the ambient assessment must match.

The home screen feels intentional and confident. The ambient assessment screens currently feel like a different product. Fix that.

---

## GLOBAL CHANGES — APPLY FIRST, BEFORE TOUCHING ANY SCREEN

### 1. Page Background
```css
/* Every screen in the ambient path */
background-color: #F7F6F4;  /* warm beige — NOT white */
```

### 2. Card Backgrounds
```css
/* Standard cards */
background-color: #FFFFFF;
border: 1px solid #E8E8E8;
border-radius: 14px;
padding: 28px 32px;

/* Featured / highlighted cards */
background-color: #FFFFFF;
border-left: 4px solid #EA2C00;
border-top: 1px solid #E8E8E8;
border-right: 1px solid #E8E8E8;
border-bottom: 1px solid #E8E8E8;
border-radius: 14px;
padding: 28px 28px 28px 24px;
```

### 3. Typography — Lock These Values
```
Screen headline:   Manrope 700, 44px desktop / 32px mobile, #0F0F0F
Section label:     Manrope 600, 11px, #A3A3A3, uppercase, letter-spacing 2px
Body text:         Manrope 400, 17px, #525252, line-height 1.75
Data numbers:      Manrope 700, contextual size, #0F0F0F or #EA2C00
Input labels:      Manrope 600, 13px, #525252
Footnote:          Manrope 400, 13px, #A3A3A3 italic
```

### 4. Remove All These Immediately
- Any green color anywhere
- Any amber/yellow color anywhere  
- Any emoji icons (Frown, Meh, Smile, PartyPopper)
- Any gradient backgrounds
- "Continue" or "Next" on any button

### 5. Spacing Rhythm
```
Page max-width:           640px centered
Page padding horizontal:  40px desktop / 20px mobile
Screen top padding:       72px
Between major sections:   56px
Between cards:            16px
Card internal padding:    28px 32px
Between label and content: 12px
```
