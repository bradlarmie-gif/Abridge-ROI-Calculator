## WHAT WE'RE BUILDING

Four sequential screens — one per domain. Each screen is a collaborative conversation with the CMO about what their organization has actually done with ambient AI in that dimension. The activation state they select drives their domain score. The numbers they enter drive the dollar gap.

This is not a form. It is an experience.

The four screens appear after Screen 3 (Performance inputs) and before the Score screen.

## DOMAIN 1 — CAPACITY

**Screen label:** CAPACITY
**Headline:** Where does recovered time actually go?
**Reframe:** Most organizations measure ambient AI by physician satisfaction. The real question is what happened to the time it returned — and whether your organization has a system for capturing it.

### Activation Cards:

```
Card 01:
Number: 01
Label: Not yet captured
Description: Time returned but not systematically redeployed

Card 02:
Number: 02
Label: Informally tracked
Description: Some backlog reduction, ad hoc improvements

Card 03:
Number: 03
Label: Actively managed
Description: Measurable OT reduction and backlog clearance

Card 04:
Number: 04
Label: Systematically deployed
Description: Recovered time drives panel growth and revenue
```

### Inputs + Feedback by State:

**State 01 — Not yet captured:**
```
No inputs required.

Feedback card:
Value: calculated from providers + encounters
Formula: providers × 2000 encounters × (4.0 - timeSavings) / 60 × 150 × 0.25
Label: Estimated undeployed capacity value
Context: "At your scale, undeployed recovered time represents an 
estimated [X] hours annually — [X.X] FTE of clinical capacity 
currently evaporating."
Footnote: "Based on Abridge benchmark: 4.0 min avg time returned"
```

**State 02 — Informally tracked:**
```
Input:
Label: ESTIMATED REDEPLOYMENT
Description: What % of recovered time is being redeployed productively?
Type: Slider 0–100%, default 20%
Display: [X]%

Feedback:
captured = totalCapacityValue × (redeployment / 100)
gap = totalCapacityValue - captured
Value: gap (the uncaptured amount)
Context: "At [X]% redeployment, approximately $[captured] is being 
captured. $[gap] remains undeployed annually."
```

**State 03 — Actively managed:**
```
Input 1:
Label: MONTHLY OT REDUCTION
Description: Estimated overtime savings per month ($)
Type: Number input with $ prefix
Placeholder: 0

Input 2:
Label: BACKLOG REDUCTION
Description: Additional patients seen per month
Type: Number input
Placeholder: 0

Feedback:
annualOT = monthlyOT × 12
annualBacklog = monthlyPatients × 200 × 12  // $200/visit
total = annualOT + annualBacklog
nextLayerValue = totalCapacityValue - total
Value: nextLayerValue
Context: "You're capturing the efficiency layer. Systematic capacity 
deployment could add an estimated $[nextLayerValue] annually."
```

**State 04 — Systematically deployed:**
```
Input 1:
Label: ADDITIONAL PATIENTS / MONTH
Description: New patients seen due to recovered capacity
Type: Number input
Placeholder: 0

Input 2:
Label: REVENUE PER VISIT
Description: Average visit revenue ($)
Type: Number input with $ prefix
Default: 200

Feedback:
annualValue = additionalPatients × revenuePerVisit × 12
benchmarkValue = providers × 2000 × (4.0 - timeSavings) / 60 × 150 × 0.25
Value: annualValue
Context: "Strong activation. Your capacity deployment is generating 
an estimated $[annualValue] annually."
```

**Domain Score:**
```typescript
const capacityScore = (() => {
  const base = { 1: 15, 2: 35, 3: 65, 4: 90 }[activationLevel] || 0;
  // Adjust within range based on inputs
  if (activationLevel === 2) {
    return Math.round(base + (redeploymentPct / 100) * 20);
  }
  if (activationLevel === 3) {
    const inputScore = Math.min(20, Math.round((monthlyOT + monthlyPatients * 200) / 1000));
    return Math.min(85, base + inputScore);
  }
  return base;
})();
```
