# SCREEN 3 — CURRENT PERFORMANCE
## Exact build prompt. Ambient AI path only.

---

## WHAT THIS SCREEN DOES

This is where the CMO first sees the Abridge benchmark directly compared to their current tool. Two inputs only — utilization and time saved. These two numbers are the foundation everything else builds on.

This screen has one job: make the gap feel real before they've seen a single dollar figure.

The Abridge benchmark is not presented as a sales claim. It's presented as a peer reference — the way a department chair would cite a published benchmark. Matter of fact. Confident. No celebration.

## CALCULATIONS

```typescript
const theirEncounters = Math.round(annualEncounters * (utilization / 100));
const abridgeEncounters = Math.round(annualEncounters * 0.76);
const encounterGap = Math.max(0, abridgeEncounters - theirEncounters);

const theirHours = Math.round((theirEncounters * timeSavings) / 60);
const abridgeHours = Math.round((abridgeEncounters * 4.0) / 60);
const hourGap = Math.max(0, abridgeHours - theirHours);

// Insight line calculations
const hoursLostToUtilGap = Math.round(
  (encounterGap * timeSavings) / 60
);
const hoursLostToEffGap = Math.round(
  (theirEncounters * Math.max(0, 4.0 - timeSavings)) / 60
);
```
