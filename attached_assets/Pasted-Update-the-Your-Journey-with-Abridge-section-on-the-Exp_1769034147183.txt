7. CHART DATA STRUCTURE
javascriptCopy// Generate chart data points
const generateChartData = () => {
  const data = [];
  const valuePerProviderLinear = pilotValue / pilotProviders;
  
  for (let providers = pilotProviders; providers <= fullScaleProviders; providers += 10) {
    // Linear projection (simple multiplication)
    const linearValue = valuePerProviderLinear * providers;
    
    // Actual value (with utilization scaling)
    // Utilization increases from pilotUtilization to targetUtilization as providers increase
    const utilizationScale = pilotUtilization + 
      ((targetUtilization - pilotUtilization) * 
       ((providers - pilotProviders) / (fullScaleProviders - pilotProviders)));
    
    // Value increases faster than linear due to utilization + other compounding effects
    const actualValue = (providers * encountersPerProvider * (utilizationScale / 100) * valuePerEncounter) 
      * (1 + (providers / fullScaleProviders) * 0.15); // 15% compounding factor at full scale
    
    data.push({
      providers,
      linearValue: Math.round(linearValue),
      actualValue: Math.round(actualValue)
    });
  }
  
  return data;
};
The goal is to show visually that scaling with Abridge isn't just "more of the same" — it's compounding value that grows faster than a linear projection would suggest.
