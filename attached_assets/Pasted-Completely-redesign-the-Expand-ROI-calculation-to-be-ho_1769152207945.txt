Completely redesign the Expand ROI calculation to be honest, defensible, and tiered. The current approach double-counts and inflates numbers. This new approach separates hard value from soft value.

## CORE PRINCIPLES

1. **Don't double-count time metrics** — Time Savings, Work Outside Work, and Chart Closure all measure the same underlying improvement
2. **Let users choose their conversion story** — Not everyone converts time to dollars
3. **Tier the value clearly** — Hard value (dollars) vs. Soft value (metrics) vs. Leading indicators
4. **Be conservative by default** — Better to under-promise and over-deliver
5. **Show the math transparently** — Every dollar should be traceable
