Replit Prompt for Simplified Data Entry
CopyRedesign the Expand data entry flow to be simpler and more progressive. The current approach asks for too much detail upfront. Most users want quick entry with the option for detail.

## PRINCIPLES

1. **Simple by default**: Ask for ONE number before and ONE number after
2. **Progressive disclosure**: Hide complexity behind "I want to enter more detail"
3. **Accordion layout**: One metric expanded at a time, collapsed ones show summary
4. **Smart defaults**: Pre-fill with benchmarks where possible
5. **Paste-friendly**: Let users paste from reports when possible

## METRIC SIMPLIFICATIONS

### Time Savings
Keep as-is. Simple before/after works.
- Before: [X] minutes
- After: [Y] minutes

### Work Outside of Work
Keep as-is. Simple before/after works.
- Before: [X] hours/week
- After: [Y] hours/week

### Level of Service (SIMPLIFY)
Default to asking for the AVERAGE E&M level, not the full distribution.

Simple mode (default):
- Before average: [3.19]
- After average: [3.58]

Include helper text:
"Calculate your average: Sum of (% at each level × level number)"
"Example: 5% L5 + 35% L4 + 42% L3 + 10% L2 + 8% L1 = 3.19"

Optional expansion: "▸ Enter full distribution instead"
When expanded, show the 5-level breakdown with Before/After columns.
Auto-calculate the average from their inputs.

### wRVU Capture
Keep as-is. Simple before/after works.
- Before: [X] wRVU/encounter
- After: [Y] wRVU/encounter

### Chart Closure Time (SIMPLIFY)
Default to asking for ONE number: same-day closure rate.

Simple mode (default):
- Before: [X]% same-day closure
- After: [Y]% same-day closure

Optional expansion: "▸ Enter full breakdown (24h, 48h, 72h+)"
When expanded, show the 4-bucket breakdown.

### Clinician Satisfaction
Keep as-is. Simple before/after works.
- Before: [X] / 10
- After: [Y] / 10

Optional: "% who would recommend Abridge"

## PAGE LAYOUT

Use accordion-style layout:
- Show all metrics as collapsed rows
- One metric expanded at a time
- Clicking a row expands it and collapses the previous one
- Completed metrics show a checkmark and summary value
- Incomplete metrics show an empty circle

```jsx
<div className="metric-accordion">
  {metrics.map(metric => (
    <div 
      key={metric.id}
      className={`metric-row ${expanded === metric.id ? 'expanded' : ''} ${metric.completed ? 'completed' : ''}`}
      onClick={() => setExpanded(metric.id)}
    >
      <div className="metric-row-header">
        <span className="status-icon">
          {metric.completed ? '✓' : expanded === metric.id ? '●' : '○'}
        </span>
        <span className="metric-name">{metric.name}</span>
        <span className="metric-summary">
          {metric.completed ? metric.summaryText : 'Not entered yet'}
        </span>
        <span className="expand-icon">{expanded === metric.id ? '▼' : '▶'}</span>
      </div>
      
      {expanded === metric.id && (
        <div className="metric-row-content">
          {/* Simple input by default */}
          <div className="simple-entry">
            <div className="entry-columns">
              <div className="entry-column">
                <label>BEFORE ABRIDGE</label>
                <input type="number" value={metric.before} onChange={...} />
                <span className="unit">{metric.unit}</span>
              </div>
              <div className="entry-arrow">→</div>
              <div className="entry-column">
                <label>AFTER ABRIDGE</label>
                <input type="number" value={metric.after} onChange={...} />
                <span className="unit">{metric.unit}</span>
              </div>
              <div className="entry-column change">
                <label>CHANGE</label>
                <div className="change-value">{metric.changeText}</div>
              </div>
            </div>
          </div>
          
          {/* Optional detailed entry */}
          {metric.hasDetailedEntry && (
            <button className="detailed-toggle" onClick={() => setShowDetailed(!showDetailed)}>
              {showDetailed ? '▾ Hide detailed entry' : '▸ Enter detailed breakdown'}
            </button>
          )}
          
          {showDetailed && (
            <div className="detailed-entry">
              {/* Metric-specific detailed entry UI */}
            </div>
          )}
          
          {/* Benchmark */}
          <div className="benchmark-note">
            📊 Benchmark: {metric.benchmarkText}
          </div>
        </div>
      )}
    </div>
  ))}
</div>
