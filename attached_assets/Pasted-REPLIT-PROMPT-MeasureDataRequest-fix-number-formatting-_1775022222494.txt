  Fix 1 — Format large numbers with commas in deployment inputs

  The deployment inputs (Total Providers, Live on Abridge, MRUs, Total Encounters, Abridge Encounters) use type="number" which shows raw unformatted numbers. Switch them to formatted text inputs that display
   commas but store numbers.

  For each of the 5 deployment number inputs, replace the <input type="number" ...> pattern with this approach — using type="text" with comma formatting:

  // Helper function — add near the top of the file with other helpers:
  function formatWithCommas(val: number | string): string {
    if (val === '' || val === 0 || val === null || val === undefined) return '';
    const num = typeof val === 'string' ? val.replace(/,/g, '') : String(val);
    if (isNaN(Number(num))) return String(val);
    return Number(num).toLocaleString('en-US');
  }

  function parseCommas(val: string): number {
    const clean = val.replace(/,/g, '');
    const n = Number(clean);
    return isNaN(n) ? 0 : n;
  }

  Then for each deployment number input (totalProviders, liveProviders, mruProviders, totalEncounters, abridgeEncounters), change type="number" to:

  <input
    type="text"
    inputMode="numeric"
    value={formatWithCommas(deployment.FIELD_NAME || '')}
    placeholder="—"
    onChange={(e) => {
      const raw = e.target.value.replace(/[^0-9]/g, '');
      updateDeployment({ FIELD_NAME: raw === '' ? 0 : Number(raw) });
    }}
    className="..."  // keep existing className unchanged
  />

  Replace FIELD_NAME with the actual field name for each input. Do the same for the MetricRow component's before/after inputs (around line 114) — these use type="number" too. Apply the same text+inputMode
  pattern with formatWithCommas for display and parseCommas for storing.
