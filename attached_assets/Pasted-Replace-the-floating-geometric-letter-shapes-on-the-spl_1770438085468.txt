APPROACH: Use the image as a background with CSS to recolor it.

Option A (preferred — CSS filter approach):

.hero-background-pattern {
  position: absolute;
  top: 0;
  left: 0;
  width: 100%;
  height: 100%;
  background-image: url('/abridge-pattern.png');
  background-size: 400px 400px;  /* tile size — adjust */
  background-repeat: repeat;
  
  /* Convert the red to dark gray to match theme */
  filter: grayscale(100%) brightness(0.18);
  
  /* Very subtle — barely visible like the old shapes */
  opacity: 0.12;
  
  /* Sit behind content */
  z-index: 0;
  pointer-events: none;
}

Option B (if the image has transparency — white background

STEP 4: SUBTLE ANIMATION

Add a very slow, subtle animation that draws you in without 
being distracting. NOT a bounce, spin, or pulse. Think: 
slow drift, like looking at a pattern through gently 
moving water.

.hero-background-pattern {
  /* ... all the above styles ... */
  
  /* Slow diagonal drift animation */
  animation: patternDrift 60s linear infinite;
}

@keyframes patternDrift {
  0% {
    background-position: 0px 0px;
  }
  100% {
    background-position: 400px 400px;
    /* Move exactly one tile width so it loops seamlessly */
    /* Must match background-size */
  }
}

This creates a very slow diagonal movement — it takes 
60 seconds to complete one cycle. At that speed, you 
barely notice it's moving, but it gives the page a 
subtle sense of life.

ALTERNATIVE ANIMATION (even more subtle — scale breathe):

@keyframes patternBreathe {
  0% {
    background-size: 400px 400px;
    opacity: 0.10;
  }
  50% {
    background-size: 420px 420px;
    opacity: 0.14;
  }
  100% {
    background-size: 400px 400px;
    opacity: 0.10;
  }
}

.hero-background-pattern {
  animation: patternBreathe 20s ease-in-out infinite;
}

This makes the pattern slowly "breathe" — scaling slightly 
and fading slightly in and out. Very organic. Pick 
whichever feels better, or combine both:

animation: patternDrift 60s linear infinite, 
           patternBreathe 20s ease-in-out infinite;
