WHAT IS A "DOCUMENTATION EVENT"?
Add this explanation as a tooltip or expandable section:
Copyⓘ What counts as a documentation event?

A documentation event is any patient interaction that requires 
structured charting in your EMR, including:

✓ Initial patient assessments
✓ Shift-to-shift handoffs
✓ Medication administration records
✓ Vital signs documentation
✓ Care plan updates
✓ Discharge summaries

For calculation purposes, use your organization's annual 
admission count divided by number of nursing FTEs as a 
starting estimate.

Update the baseline calculation:
javascriptCopy// OLD (hardcoded)
const eventsPerFTE = 500;

// NEW (user input)
const eventsPerFTE = parseInt(document.getElementById('events-per-fte').value) || 500;

// Calculate baseline
const nurseFTEs = parseInt(document.getElementById('nurse-ftes').value) || 150;
const totalEvents = nurseFTEs * eventsPerFTE;
const utilization = getSelectedUtilization(); // 50%, 65%, 80%
const eligibleEvents = Math.round(totalEvents * (utilization / 100));
