   - Third is AUTO-CALCULATED (grayed out, not editable)

   CAN'T LOCK ALL THREE:
   - Disable third lock button if two are already locked
   - Tooltip: "At least one category must adjust automatically"

   When locked:
   - Lock icon changes color (gray → coral)

   - Or add thin left border in Abridge red
   
   When auto-calculated:
   - Input field is grayed out
   - Shows 🔢 icon instead of lock
   - Helper text below: "Calculated automatically"

4. INTERACTION:

   Click lock icon → toggles lock state
   Click input → unlock automatically and focus input
   (or show confirmation: "Unlock to edit?")
