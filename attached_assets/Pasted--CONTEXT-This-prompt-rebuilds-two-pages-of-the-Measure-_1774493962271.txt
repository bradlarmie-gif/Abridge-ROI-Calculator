  This prompt rebuilds two pages of the Measure path from scratch:

  Page 2 — "What You're Measuring" (currently the broken Select Metrics page): data entry for before/after or monthly metrics, organized by domain and chapter, fast enough for pre-call CSM prep, clean enough

  Design principles

  - Single Abridge orange (#EA2C00) as the only accent color. No green/blue/teal domain dots.
  - Optimized for pre-call prep — keyboard-navigable, tab between fields, fast
  - Domain sections with left orange border when active, gray when empty

  - Metric inactive state: name + one-line description + visible "+ Measure this" button
  - Metric active state: large before/after inputs with immediate delta, OR monthly grid with live sparkline
  - Entry state is welcoming, not "0 of 21 active"

  MetricBar component — the visual centerpiece

  function MetricBar({ metric, delay }) {
    const delta = metric.after - metric.before;
    const deltaPercent = (delta / metric.before) * 100;
    const improved = metric.higherIsBetter ? delta > 0 : delta < 0;

    // Bar fill: represents "after" as proportion of "before"
    // For lower-is-better: fill shrinks (after/before × 100%)
    // For higher-is-better: fill grows (after/before × 100%, capped at 100% visual, overflow indicated)
    const barWidth = Math.min((metric.after / metric.before) * 100, 100);
    const isOverflow = metric.higherIsBetter && metric.after > metric.before;

    return (
      <div>
        {/* Label row */}
        <div className="flex items-center justify-between mb-2">
          <p className="text-sm font-medium text-[#1A1A1A]">{metric.label}</p>
          <motion.span
            initial={{ opacity: 0, x: 8 }}
            animate={{ opacity: 1, x: 0 }}
            transition={{ delay: delay + 0.4 }}
            className={`text-base font-bold ${improved ? 'text-green-600' : 'text-red-500'}`}
          >
            {improved ? '↓' : '↑'} {Math.abs(deltaPercent).toFixed(1)}%
          </motion.span>
        </div>

        {/* Bar track */}
        <div className="relative h-3 bg-[#F0F0F0] rounded-full overflow-hidden mb-2">
          {/* Ghost bar showing baseline (before) at 100% */}
          <div className="absolute inset-0 bg-[#F0F0F0] rounded-full" />
          {/* Animated orange bar showing "after" */}
          <motion.div
            className="absolute inset-y-0 left-0 rounded-full"
            style={{ backgroundColor: improved ? '#EA2C00' : '#F87171' }}
            initial={{ width: '100%' }}
            animate={{ width: `${barWidth}%` }}
            transition={{ delay, duration: 0.8, ease: 'easeOut' }}
          />
        </div>

        {/* Before / after labels */}
        <div className="flex items-center justify-between">
          <span className="text-xs text-[#999999]">
            Before: <span className="font-medium text-[#666666]">{metric.before}{metric.unit ? ` ${metric.unit}` : ''}</span>
          </span>
          <span className="text-xs text-[#999999]">
            Now: <span className="font-semibold text-[#1A1A1A]">{metric.after}{metric.unit ? ` ${metric.unit}` : ''}</span>
          </span>
        </div>

        {/* Multi-setting rows (if applicable) */}
        {metric.settingRows && metric.settingRows.length > 1 && (
          <div className="mt-2 space-y-1 pl-3 border-l-2 border-[#F0F0F0]">
            {metric.settingRows.map(row => (
              <p key={row.setting} className="text-xs text-[#999999]">
                <span className="capitalize">{row.setting}:</span>{' '}
                {row.before} → {row.after}
                {' · '}
                <span className={row.improved ? 'text-green-600' : 'text-red-500'}>
                  {Math.abs(row.deltaPercent).toFixed(1)}%
                </span>
              </p>
            ))}
          </div>
        )}

        {/* Plain-English interpretation — rendered if available */}
        {metric.plainEnglish && (
          <p className="text-xs text-[#888888] mt-2 leading-relaxed italic">
            {metric.plainEnglish}
          </p>
        )}
      </div>
    );
  }

  The bar animation: starts at 100% width (baseline) and animates DOWN to the "after" proportion. For lower-is-better metrics, the bar shrinking = improvement. The orange color fills the "remaining" portion.
   It's immediately intuitive — you see the bar get shorter and the percentage decrease. No explanation needed.
