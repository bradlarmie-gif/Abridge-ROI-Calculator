# SCORE SCREEN — COMPLETE REDESIGN
## The score must feel earned. Not random.

---

## THE CORE PROBLEM TO FIX

The current score appears as a standalone number with no visible connection to how it was calculated. A CMO sees 50/100 and immediately thinks "why 50?" That question destroys credibility.

The fix: the score is built visibly from the four domain scores in real time. The CMO can see exactly what is driving it — and more importantly, what is dragging it down.

---

## SCREEN ARCHITECTURE

Three sequential sections on one screen revealed with staggered animation:

```
SECTION A — The Build-Up (domains → score)
SECTION B — The Verdict (score in context)
SECTION C — The Implication (what this means)
```

---

**Domain score values:**
```typescript
// These come directly from the four domain screens
// Each domain's activation level + inputs determine its score

const domainScores = {
  capacity:  capacityScore,   // 15 | 35 | 65 | 90 (modified by inputs)
  revenue:   revenueScore,    // 10 | 30 | 62 | 88
  workforce: workforceScore,  // 20 | 40 | 65 | 85
  risk:      riskScore,       // 15 | 38 | 62 | 90

// Weights
const documentationScore = Math.round(
  (domainScores.capacity  * 0.30) +
  (domainScores.revenue   * 0.25) +
  (domainScores.workforce * 0.25) +
  (domainScores.risk      * 0.20)
);
```

## CALCULATIONS REFERENCE

```typescript
// Domain scores from domain screens:
// capacityScore:  base {1:15, 2:35, 3:65, 4:90} + input modifier
// revenueScore:   base {1:10, 2:30, 3:62, 4:88}
// workforceScore: base {1:20, 2:40, 3:65, 4:85}
// riskScore:      base {1:15, 2:38, 3:62, 4:90}

const documentationScore = Math.round(
  (capacityScore  * 0.30) +
  (revenueScore   * 0.25) +
  (workforceScore * 0.25) +
  (riskScore      * 0.20)
);

// Lowest domain identification:
const domainScoreMap = {
  Capacity:  capacityScore,
  Revenue:   revenueScore,
  Workforce: workforceScore,
  Risk:      riskScore,
};

const lowestDomain = Object.entries(domainScoreMap)
  .sort(([,a], [,b]) => a - b)[0][0];

// Score improvement projection:
const nextLevelScore = (current: number): number => {
  if (current < 35) return 35;
  if (current < 65) return 65;
  if (current < 90) return 90;
  return current;
};

const improvedDomainScore = nextLevelScore(
  domainScoreMap[lowestDomain]
);

const improvedTotal = Math.round(
  documentationScore + 
  ((improvedDomainScore - domainScoreMap[lowestDomain]) * 
   domainWeights[lowestDomain])
);
```
