## ONE ADDITIONAL FIX ACROSS ALL PAGES

Anywhere the PDF shows "0" for a value that wasn't entered (as opposed to actually being zero), change to "—". This applies to:
- Time saved: 0 min → "—" if not entered
- Hours reclaimed: 0 hrs → "—" if derived from unentered time saved
- FTE equivalent: 0.0 → "—" if derived from unentered time saved
- Any domain measured value that shows $0 because inputs weren't provided → "—"

The rule: "0" means "we measured it and it's zero." "—" means "not yet entered." These are different things and the PDF should reflect that.
