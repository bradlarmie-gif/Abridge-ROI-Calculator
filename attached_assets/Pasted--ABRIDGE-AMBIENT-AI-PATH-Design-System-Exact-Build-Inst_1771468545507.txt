# ABRIDGE AMBIENT AI PATH
## Design System + Exact Build Instructions
### Ambient AI path only. Every decision is final.

---

## THE STANDARD

This tool is used by CMOs and CMIOs at health systems that already have ambient AI. They are clinically trained, intellectually rigorous, and skeptical of vendor tools. They will forward this to their CFO or they won't. That is the only quality gate.

**Premium for this audience means:**
- It respects their intelligence on every screen without exception
- The math survives an analyst's scrutiny
- The visual language signals institutional authority, not startup enthusiasm
- They would be comfortable showing it to a peer without adding a disclaimer

Current state: Concept 8 / Execution 3 / UX 4.
Target: Concept 8 / Execution 9 / UX 9.

The gap is closed through subtraction, consistency, and discipline. Not more features.

## PART 1: THE DESIGN SYSTEM

This is the law. Every element on every screen follows these rules. No exceptions. No approximations.

---

### TYPOGRAPHY

**One system. Applied everywhere.**

```
Display / Hero:
  Font:    Manrope
  Size:    48px desktop / 36px mobile
  Weight:  700 (Bold)
  Color:   #1A1A1A
  Usage:   Screen headlines only. One per screen.

Section Headline:
  Font:    Manrope
  Size:    28px desktop / 22px mobile
  Weight:  600 (SemiBold)
  Color:   #1A1A1A
  Usage:   Major content blocks

Body:
  Font:    Manrope
  Size:    17px desktop / 16px mobile
  Weight:  400 (Regular)
  Color:   #4B4B4B
  Line height: 1.75
  Usage:   All descriptive text, explanations

Label / Eyebrow:
  Font:    Manrope
  Size:    11px
  Weight:  600
  Color:   #9B9B9B
  Letter spacing: 2px
  Transform: UPPERCASE
  Usage:   Section identifiers, metadata

Data / Numbers:
  Font:    Manrope
  Size:    Contextual — 72px for hero numbers,
           32px for card numbers, 20px for inline
  Weight:  700
  Color:   #1A1A1A (default) or #EA2C00 (primary metric)
  Usage:   All numerical values

Footnote:
  Font:    Manrope
  Size:    13px
  Weight:  400
  Color:   #9B9B9B
  Usage:   Assumptions, caveats, methodology notes
```

**NEVER use:**
- Font sizes below 13px for any user-facing content
- Font weights other than 400, 600, 700
- Color for text other than #1A1A1A, #4B4B4B, #9B9B9B, #EA2C00, or #FFFFFF

### COLOR

**Five colors. That's it.**

```
Brand Red:       #EA2C00
  Usage: Primary CTA buttons, active states, score bar fill,
         accent borders on featured cards, primary metric numbers.
         NEVER for body text. NEVER decoratively.

Near Black:      #1A1A1A
  Usage: All headlines, data numbers, verdict statements.

Body Gray:       #4B4B4B
  Usage: All body copy, descriptions, explanations.

Secondary Gray:  #9B9B9B
  Usage: Labels, footnotes, secondary metadata, benchmarks.

Background Warm: #F7F6F4
  Usage: Card backgrounds, section backgrounds, input fields.
  NOT pure white — the warmth signals premium print quality.

White:           #FFFFFF
  Usage: Primary page background only.
```

**ELIMINATE IMMEDIATELY:**
- All emerald/green (#10B981 and variants) — remove from every value display
- All amber (#F59E0B and variants) — remove from warnings, use #9B9B9B instead
- All blue — not in this tool
- All gradient backgrounds

**Positive values display in #1A1A1A bold — not green.**
This is a diagnostic. Green reads as celebratory. This content is analytical.
The red (#EA2C00) is used only for the primary metric — the gap number.

### TRANSITIONS & ANIMATION

**Rules:**

```
Screen transitions:     fade, 200ms, ease-out. Nothing else.
Content reveal:         fade + translateY(8px → 0), 300ms, ease-out
Number count-up:        duration 1200ms, ease-out cubic
Score bar fill:         duration 600ms, ease-out, left to right
CTA delayed appearance: specific delays noted per screen — use opacity transition
```

**ELIMINATE:**
- Slide transitions (too casual)
- Bounce (never)
- Scale animations on cards (too playful)
- Pulse animations except the single red dot on Benchmark Mirror
- The `liftButton` animation currently in the CSS
- The `successPulse` animation

**The only animations that remain:**
1. Fade in/out between screens
2. Content sections revealing sequentially (fade + slight upward movement)
3. Score bar filling on Step 7
4. Number counting up on Step 7
5. Single pulsing dot on Benchmark Mirror (slow pulse, 3s cycle, subtle)
6. CTA button appearing with delay on Steps 4, 5, 6

### COPY VOICE — LOCKED

**The voice is a respected department chair presenting at Grand Rounds.**

Not a salesperson. Not a chatbot. Not a startup. A peer.

```
✓ Precise but accessible
✓ Short declarative sentences
✓ Evidence-referenced without being academic  
✓ Confidence through restraint
✓ Numbers on their own line — always
✓ "Already in your operations" — use this phrase
✗ No exclamation points
✗ No "unlock", "transform", "revolutionize", "empower"
✗ No dramatic punctuation (no "Every. Single. Year.")
✗ No hedging ("might", "could potentially", "may")
✗ No explaining the obvious
✗ No green checkmarks celebrating data points
```

**Score calculation:**
```typescript
const utilizationPct = Math.min(100, 
  Math.round((utilization / 76) * 100));
const efficiencyPct = Math.min(100, 
  Math.round((timeSavings / 4.0) * 100));
const driverPct = Math.min(100,
  Math.round((selectedDrivers.length / 6) * 100));
const confidencePct = 
  confidenceMode === 'measured' ? 90 : 
  confidenceMode === 'estimated' ? 65 : 40;

const enterpriseScore = Math.round(
  (utilizationPct * 0.35) +
  (efficiencyPct * 0.30) +
  (driverPct * 0.20) +
  (confidencePct * 0.15)
);
```
