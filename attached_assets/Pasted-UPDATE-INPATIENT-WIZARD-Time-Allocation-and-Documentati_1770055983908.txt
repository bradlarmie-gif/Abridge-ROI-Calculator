CALCULATION FORMULAS:
═══════════════════════════════════════════════════════════

CLINICAL OPERATIONS (if LOS toggled ON):
netValue = admissions × docDelayRate × timeRecovered × revenuePerBedHour × attributionFactor

PHYSICIAN WELLBEING:
hoursPerPhysicianPerYear = (totalHoursSaved × wellbeingAllocation) / numPhysicians
hoursPerWeek = hoursPerPhysicianPerYear / 52

// Threshold logic
if (hoursPerPhysicianPerYear < 100) retentionLift = 0.05
else if (hoursPerPhysicianPerYear < 150) retentionLift = 0.12
else retentionLift = 0.17

annualDepartures = numPhysicians × turnoverRate
physiciansRetained = annualDepartures × retentionLift
wellbeingValue = physiciansRetained × replacementCost

DRG ACCURACY:
atRiskAdmissions = admissions × atRiskRate
protectedAdmissions = atRiskAdmissions × protectionRate
grossValue = protectedAdmissions × drgWeightLift × baseDrgPayment
netValue = grossValue × realizationRate

CDI QUERY REDUCTION:
totalQueries = admissions × queryRate
queriesAvoided = totalQueries × reductionRate
savings = queriesAvoided × costPerQuery
