## Single instruction for Replit — Ambient AI path only

---

## WHO THIS IS FOR — READ THIS FIRST

Every design decision in this document is made for one specific person:

**The CMO or CMIO at a health system that already uses ambient AI.**

They are clinically trained. Intellectually rigorous. They made the decision to deploy ambient AI and it went well — physicians are happier, satisfaction scores are up. They believe the problem is solved.

They are not looking to be sold to. They are not looking for a calculator. They are not in pain.

**The only thing that moves this person is a question they haven't thought to ask yet.**

The assessment's entire job is to surface that question — calmly, credibly, without pressure. By the end, the CMO should feel genuinely curious. Not scared. Not urgent. *Curious.* Like they just read something in a journal that made them want to call a colleague and say "have you seen this?"

**That is the only success criterion for this assessment.**

Everything — the sequence, the math, the copy, the UX — exists to create that one moment of intellectual curiosity in a person who walked in certain they didn't need it.

## GLOBAL DESIGN RULES

These apply to every screen without exception.

**Typography hierarchy:**
- Screen titles: Manrope, 40–48px, bold, near-black (#1A1A1A)
- Body: Manrope, 17px, 1.7 line height, #4B4B4B
- Labels: Manrope, 11px, uppercase, tracked 2px, #9B9B9B
- Numbers/verdicts: Manrope, large, bold, either #1A1A1A or #EA2C00
- Never use font sizes below 13px for any content a CMO needs to read

**Spacing:**
- Minimum 80px vertical padding top and bottom on every screen
- Minimum 32px between major content sections
- Cards: 24px internal padding minimum
- Let content breathe — white space signals confidence

**Color usage:**
- #EA2C00 for: CTAs, active states, key numbers, score bar fill, accent lines
- #1A1A1A for: headlines, verdicts, primary data
- #4B4B4B for: body text, descriptions
- #9B9B9B for: labels, secondary info, footnotes
- #F7F6F4 for: card backgrounds, subtle sections
- White for: primary background
- Never use green for positive numbers — this is a diagnostic tool, not a financial dashboard. Use #1A1A1A bold instead.

**Interactions:**
- All screen transitions: fade, 250ms
- CTAs: never say "Continue" or "Next" — always directional
- No tooltips that require hovering — CMOs on mobile will miss them
- Input fields: large, clean, border-2 neutral, focus ring EA2C00
- Never auto-advance without user intent except where specifically noted

**Tone:**
- Clinical authority. Not friendly. Not cold. Like a respected colleague.
- Short sentences. One idea per sentence.
- No exclamation points. Ever.
- No "unlock", "transform", "revolutionize", "empower"
- Numbers get their own line. Always.
- "Already in your operations" — use this phrase. It reframes loss as recovery.

## CONFIDENCE HAIRCUT — ONE PLACE ONLY

Add state:
```typescript
const [confidenceMode, setConfidenceMode] = 
  useState<'benchmark' | 'estimated' | 'measured'>('benchmark');

const CONFIDENCE_HAIRCUTS = {
  benchmark: 0.55,
  estimated: 0.72,
  measured: 0.88,
};

const haircut = CONFIDENCE_HAIRCUTS[confidenceMode];
```

Apply haircut ONLY to displayed values:
```typescript
const displayedTotal = Math.round(calculations.totalGap * haircut);
const displayedMonthly = Math.round(calculations.monthlyGap * haircut);
```

Remove ALL internal realization multipliers from engine calculations.
The haircut is the single conservatism mechanism.

## MATH FIXES — APPLY TO CALCULATION ENGINE

**Fix the retention formula phantom variable:**

Remove the hardcoded `effectivenessGap = 0.50` assumption. Replace with:
```typescript
// Abridge effectiveness advantage is surfaced as an editable assumption
// Default: 40% improvement over current tool (conservative)
const abridgeEffectivenessAdvantage = retAssumptions.effectivenessAdvantage / 100; // default 40
const retentionGap = Math.round(
  providers * 
  (turnoverRate / 100) * 
  (burnoutReduction / 100) * 
  abridgeEffectivenessAdvantage * 
  replacementCost
);
```

Add `effectivenessAdvantage: 40` to `DEFAULT_ASSUMPTIONS.retention`.

**Fix the double-count in HCC and Denials:**

For both HCC and Denials, the gap should be calculated only on the utilization-adjusted encounters, not split between utilization gap encounters AND rate improvement separately. Simplify:

```typescript
// Denials: calculate on Abridge encounter volume vs current encounter volume
const denialsGap = Math.round(
  (abridgeDocumentedEncounters - theirDocumentedEncounters) * 
  (denialRate / 100) * 
  (docRelatedRate / 100) * 
  (ABRIDGE_BENCHMARKS.denialPrevention / 100) * 
  avgClaimValue
) + Math.round(
  theirDocumentedEncounters *
  ((ABRIDGE_BENCHMARKS.denialPrevention - denialPrevention) / 100) *
  (denialRate / 100) *
  (docRelatedRate / 100) *
  avgClaimValue
);
// Same pattern for HCC
```

**Add encounters-per-provider guardrail:**
```typescript
const encPerProvider = providers > 0 ? annualEncounters / providers : 0;
const showEncounterWarning = encPerProvider > 3500;
// Show below encounters input: 
// "That's ~[X] per provider per day — want to double-check?"
```

## COPY VOICE REFERENCE

For any copy written beyond what is specified above, match this voice:

**Write like a department chair giving a Grand Rounds presentation.**
- Precise but accessible
- Evidence-referenced but not academic
- No hedging, no overselling
- Confidence through restraint — the less you say, the more it lands
- Short declarative sentences
- Never explain the obvious

**Wrong:** "Ambient AI is a powerful technology that can transform your organization's documentation workflows and unlock significant value across multiple dimensions."
