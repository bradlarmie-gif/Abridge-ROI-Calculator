OBJECTIVE:
Build the "New Care Setting" scenario flow. User clicks "New Care Setting" from the scenario type cards and can model expansion into Emergency Department or Nursing. Shows combined deployment value across multiple care settings.

CRITICAL RULES:

- ED uses same pricing as Outpatient
- Nursing has different pricing (show "Contact for pricing" or placeholder)
- Pre-select relevant drivers based on care setting
- Show combined deployment preview (current + new setting)

PART 10: CALCULATION LOGIC

ED-specific defaults:
- Encounters per provider: 5,000 (vs 1,300 for outpatient)
- Baseline wRVU: 2.8 (vs 1.75 for outpatient)
- Default utilization: 70%
- Pricing: Same as Outpatient ($X/provider/month)

ED driver calculations:
- Use ED-specific baselines
- Same formulas as outpatient, different inputs

Nursing-specific defaults:
- Different calculation model (time-based, not wRVU)
- Placeholder pricing until confirmed
- Focus on time savings and overtime metrics

Combined calculations:
- Sum provider counts
- Sum encounter counts
- Calculate each setting's value independently
- Sum for combined totals
- Combined ROI = Combined Net Gain / Combined Investment

Real-time update behavior:
- Same debouncing as previous phases
- Update both new setting values AND combined totals

PART 11: SAVE BEHAVIOR

1. Validate inputs:
   - Care setting selected
   - Provider count > 0
   - At least one driver selected

   - Scenario ID (generated)
   - Scenario name
   - Scenario type: "new_care_setting"
   - Care setting: "emergency_department" or "nursing"
   - Created timestamp
   - Configuration inputs
   - Selected drivers with adjustments
   - Calculated results (new setting only)
   - Combined results (current + new)

3. Navigate back to Scenario Builder main page

4. Show success toast:
   "✓ Scenario saved: [Scenario Name]"
