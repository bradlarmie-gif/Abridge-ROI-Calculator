SECTION 0 — HOW NURSING DIFFERS FROM ALL OTHER SETTINGS
(9 critical differences — all confirmed from live wizard and bundle)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
DIFFERENCE 1 — BASELINE UNIT IS BEDS, NOT PROVIDERS OR ENCOUNTERS
  Nursing: Staffed Beds + Nurse FTEs + Bed Occupancy % + Adoption %
  → The coverage area is a hospital unit. The user of Abridge is a nurse.
  → Unit of care: "shifts" (not encounters or admissions)
  → Investment pricing: per bed per month (not per provider)
  → Metric shown: "hours saved" and "per bed/yr" (not per provider/yr)
  → NEVER use "provider," "encounter," "admission," "hospitalist," or "physician" in this PDF
DIFFERENCE 2 — TIME SAVINGS IS PER SHIFT, NOT PER ENCOUNTER/ADMISSION
  Nursing: 15–30 min/shift (Typical 20 min)
  → Formula: Nurse FTEs × 260 shifts/year × adoption% = Abridge-enabled shifts
  → Then: minutes/shift × Abridge-enabled shifts ÷ 60 = total hours/year
  → This is flowsheet documentation, not clinical note documentation
  → Language: "per shift" not "per encounter" or "per admission"
DIFFERENCE 3 — TIME ALLOCATION BUCKET NAMES (exact from wizard)
  Nursing: Overtime Reduction / Shift Sustainability / Direct Patient Care
  → Overtime Reduction: "Time that directly reduces end-of-shift overtime"
  → Shift Sustainability: "Time absorbed into shift breathing room; reduces documentation stress and supports retention"
  → Direct Patient Care: "Time returned to the bedside for assessments, interventions, and presence"
  → NEVER use "patient access," "capacity," "throughput," "documentation quality," "rounding"
DIFFERENCE 4 — LEFT CARD LABEL IS "LABOR ECONOMICS" (confirmed from bundle)
  ✓ Left card = "LABOR ECONOMICS"
  ✓ Left card description = "Overtime, retention, and agency spend. These are real dollars that show up in the budget. When nurses spend less time documenting, they finish shifts on time, burn out less, and the organization needs fewer expensive travel nurses."
  ✓ Left tagline = "The budget impact is real."
  ✓ Right card = "CARE QUALITY ENABLEMENT"
  ✓ Right card description = "Falls, pressure injuries, patient satisfaction. These outcomes are influenced by bedside time. More time caring, less time charting, better outcomes. But the causal chain is indirect — documentation supports care, it doesn't replace it."
  ✓ Right tagline = "Better care starts with better information."
DIFFERENCE 5 — VALUE DRIVERS ARE COMPLETELY UNIQUE (confirmed labels from Step 8)
  Section 1: STAFFING EFFICIENCY
    • OT Reduction           → dollar value (hard)
    • Retention Savings      → dollar value (hard)
    • Agency Reduction       → dollar value (hard, optional)
  Section 2: CARE QUALITY (labeled "potential" — distinct from hard value)
    • HAPI Risk Reduction    → dollar value (potential)
    • Fall Risk Visibility Gap → dollar value (potential)
    • HAC Penalty            → dollar value (potential, opt-in)
    • HCAHPS                 → qualitative only (no dollar value ever)
  NOT in Nursing: wRVU, HCC, DRG Accuracy, CDI, LWBS, Admission Capture, E&M Level Accuracy, Rounding Efficiency
DIFFERENCE 6 — STEP 6 IS "CARE QUALITY" NOT "DOCUMENTATION QUALITY"

DIFFERENCE 7 — HARD VALUE VS POTENTIAL VALUE IS THE CENTRAL PDF TENSION
  Hard value (Staffing Efficiency) = real dollars that show up in the budget
  Potential value (Care Quality) = real but harder to attribute directly to Abridge
  → The PDF must maintain this distinction throughout
  → Never combine hard + potential into a single net value number in body copy
  → The hero net value uses hard value only
  → Potential value gets its own dedicated treatment with clear "potential" framing
DIFFERENCE 8 — THESIS QUESTION IS UNIQUE
  ✓ Confirmed from bundle: "Nurses don't bill. So where does the value live?"
