## THE SOUL OF MEASURE

This is NOT a form. This is NOT a dashboard. This is a guided reveal of what's already happening in their data.

The core insight: We compare Abridge encounters vs non-Abridge encounters for the SAME providers. This is a natural experiment. Same doctors, same patients, different documentation method, different outcomes.

We are SHOWING them their data, not ASKING for it.

CALCULATIONS:

hardSavingsHours = totalHours × (hardSavingsPercent / 100)
hardSavingsValue = hardSavingsHours × otRate

capacityHours = totalHours × (capacityPercent / 100)
capacityVisits = capacityHours / (minutesPerVisit / 60)
capacityValue = capacityVisits × revenuePerVisit

qualityHours = totalHours × (qualityPercent / 100)
qualityHoursPerWeek = qualityHours / providers / 52

DEFAULT CALIBRATION VALUES:
- OT hourly rate: $150
- Minutes per visit: 30
- Revenue per visit: $200
- Medicare conversion factor: $33
