BEHAVIOR WHEN "CALCULATE SCENARIO" IS CLICKED:

1. VALIDATION:
- Ensure scenario name is filled (if empty, use "Scenario [number]")
- Ensure providers and encounters are > 0
- Ensure utilization is 40-90%

2. CALCULATION:
Run the ROI calculation with the scenario's inputs:

For BASIC inputs:
- Use new providers, encounters, utilization to calculate eligible encounters
- Run all existing drivers through the formulas with new encounter volume

For ADVANCED inputs (if provided):
- Adjust MA %: Recalculate HCC Capture with new MA population
- Adjust new patient %: Modify baseline wRVU calculation
  - Formula: baseline_wRVU = (new_patient_% × 2.0) + (established_% × 1.65)
- Adjust specialty mix: Modify baseline wRVU calculation  
  - Formula: baseline_wRVU = (specialty_% × 1.9) + (primary_% × 1.6)
- Revenue override: Use this instead of baseline revenue per visit
- Visit length override: Use this in Patient Access calculations

If BOTH new patient % and specialty mix are adjusted:
- Combine their effects: Specialty mix sets the base wRVU range, then new patient % adjusts within that range

3. CALCULATE INVESTMENT:
- New investment = (new providers × cost per provider × 12)
- Keep the same cost per provider from baseline model

4. CALCULATE TOTALS:
- Total benefit = sum of all driver values with new calculations
- Net gain = total benefit - investment
- ROI = total benefit / investment

5. SAVE SCENARIO:
- Add to the scenarios list
- Show it in "YOUR SCENARIOS" section
- Collapse the form
- Automatically show the comparison view (next step)

6. FEEDBACK:
Show a success message: "✓ Scenario '[name]' created"
