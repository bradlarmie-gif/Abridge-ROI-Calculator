SECTION 1: THE CONTEXT
Copy┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  THE CONTEXT                                                                    │
│  Why inpatient value is different                                               │
│                                                                                 │
│  ───────────────────────────────────────────────────────────────────────────    │
│                                                                                 │
│  Inpatient medicine operates on a fundamentally different economic model        │
│  than outpatient care.                                                          │
│                                                                                 │
│  In outpatient settings, physicians bill for each visit. More visits, more      │
│  wRVUs, more revenue. The relationship between work and payment is direct.      │
│                                                                                 │
│  Inpatient reimbursement works differently. Hospitals are paid a fixed          │
│  amount per admission based on the DRG—the Diagnosis Related Group. That        │
│  payment is determined by:                                                      │
│                                                                                 │
│  • The principal diagnosis                                                      │
│  • Complications and comorbidities (CCs and MCCs)                               │
│  • Procedures performed                                                         │
│  • Patient characteristics                                                      │
│                                                                                 │
│  Here's what matters: **The DRG is assigned based on what's documented.**       │
│                                                                                 │
│  If a condition was discussed at bedside but not documented, it doesn't         │
│  exist for coding purposes. If clinical complexity isn't captured in the        │
│  note, the DRG may be assigned lower than it should be.                         │
│                                                                                 │
│  This is where ambient documentation creates value.                             │
│                                                                                 │
│  ───────────────────────────────────────────────────────────────────────────    │
│                                                                                 │
│  THE TWO VALUE PATHS                                                            │
│                                                                                 │
│  ┌─────────────────────────────────────────────────────────────────────────┐    │
│  │                                                                         │    │
│  │  1. DOCUMENTATION QUALITY → REVENUE ACCURACY                            │    │
│  │                                                                         │    │
│  │  When documentation fully captures clinical complexity, DRGs are        │    │
│  │  assigned accurately. This isn't about "upcoding"—it's about ensuring   │    │
│  │  the code reflects the actual care delivered.                           │    │
│  │                                                                         │    │
│  │  Incomplete documentation leads to:                                     │    │
│  │  • DRG downcoding (lower payment than warranted)                        │    │
│  │  • Claim denials (payer rejects for insufficient documentation)         │    │
│  │  • CDI query burden (teams asking physicians to document what           │    │
│  │    they already discussed)                                              │    │
│  │                                                                         │    │
│  │  Better documentation prevents all three.                               │    │
│  │                                                                         │    │
│  └─────────────────────────────────────────────────────────────────────────┘    │
│                                                                                 │
│  ┌─────────────────────────────────────────────────────────────────────────┐    │
│  │                                                                         │    │
│  │  2. TIME SAVINGS → CLINICIAN WELLBEING                                  │    │
│  │                                                                         │    │
│  │  Hospitalists spend significant time on documentation—H&Ps, daily       │    │
│  │  progress notes, discharge summaries. Reducing this burden can          │    │
│  │  improve work-life balance and retention.                               │    │
│  │                                                                         │    │
│  │  Unlike outpatient, time savings don't translate to "more patients"     │    │
│  │  in the same way. Hospitalists have a census, not a schedule. The       │    │
│  │  value shows up primarily in wellbeing and operational efficiency.      │    │
│  │                                                                         │    │
│  └─────────────────────────────────────────────────────────────────────────┘    │
│                                                                                 │
│  We focus primarily on documentation quality for inpatient value—that's         │
│  where the clearest, most measurable ROI lives.                                 │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

SECTION 2: THE VALUE MECHANISMS
Copy┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                 │
│  THE VALUE MECHANISMS                                                           │
│  How documentation quality becomes dollars                                      │
│                                                                                 │
│  ───────────────────────────────────────────────────────────────────────────    │
│                                                                                 │
│  DOCUMENTATION → REVENUE ACCURACY                                               │
│  ───────────────────────────────────────────────────────────────────────────    │
│                                                                                 │
│                                                                                 │
│  ┌─────────────────────────────────────────────────────────────────────────┐    │
│  │                                                                         │    │
│  │  DRG ACCURACY (CC/MCC CAPTURE)                                          │    │
│  │                                                                         │    │
│  │  The mechanism:                                                         │    │
│  │  Every inpatient stay is assigned a DRG based on documented diagnoses.  │    │
│  │  Complications and comorbidities (CCs) and major complications (MCCs)   │    │
│  │  increase the DRG weight—and the payment.                               │    │
│  │                                                                         │    │
│  │  When a hospitalist discusses a patient's acute kidney injury,          │    │
│  │  malnutrition, or respiratory failure at bedside but doesn't fully      │    │
│  │  document it, that clinical complexity doesn't get coded. The DRG       │    │
│  │  is assigned lower than it should be.                                   │    │
│  │                                                                         │    │
│  │  Ambient documentation captures these conversations as they happen,     │    │
│  │  ensuring clinical complexity is documented—not because we're adding    │    │
│  │  things that weren't there, but because we're capturing what was        │    │
│  │  actually discussed.                                                    │    │
│  │                                                                         │    │
│  │  ─────────────────────────────────────────────────────────────────────  │    │
│  │                                                                         │    │
│  │  The calculation:                                                       │    │
│  │                                                                         │    │
│  │  Step 1: Admissions at risk of downcoding                               │    │
│  │  Admissions × At-Risk Rate = Admissions at risk                         │    │
│  │                                                                         │    │
│  │  Not every admission has documentation gaps. Research suggests          │    │
│  │  20-30% of admissions have some level of under-documentation that       │    │
│  │  affects DRG assignment.                                                │    │
│  │                                                                         │    │
│  │  Step 2: Abridge protection                                             │    │
│  │  At-Risk Admissions × Protection Rate = Admissions protected            │    │
│  │                                                                         │    │
│  │  Not every at-risk admission will be "saved" by better documentation.   │    │
│  │  We estimate Abridge captures 15-25% of these opportunities through     │    │
│  │  more complete initial documentation.                                   │    │
│  │                                                                         │    │
│  │  Step 3: Revenue protected                                              │    │
│  │  Admissions protected × DRG Weight Increase × Base DRG Payment          │    │
│  │  = Gross value                                                          │    │
│  │                                                                         │    │
│  │  When a CC or MCC is captured, DRG weight increases. The average        │    │
│  │  increase is 0.3-0.6 depending on the condition. We use 0.4 as          │    │
│  │  a blended average.                                                     │    │
│  │                                                                         │    │
│  │  Step 4: Realization rate                                               │    │
│  │  Gross value × Realization Rate = Net value                             │    │
│  │                                                                         │    │
│  │  Not every documented condition survives the coding and billing         │    │
│  │  process. RAC audits, coder discretion, payer edits, and retrospective  │    │
│  │  adjustments all take a cut. We apply a 50% realization rate—           │    │
│  │  conservative, but realistic.                                           │    │
│  │                                                                         │    │
│  │  ─────────────────────────────────────────────────────────────────────  │    │
│  │                                                                         │    │
│  │  Example:                                                               │    │
│  │  10,000 admissions × 25% at-risk = 2,500 at-risk admissions             │    │
│  │  2,500 × 20% protection rate = 500 admissions protected                 │    │
│  │  500 × 0.4 weight increase × $6,000 base payment = $1.2M gross          │    │
│  │  $1.2M × 50% realization = $600K net value                              │    │
│  │                                                                         │    │
│  │  ─────────────────────────────────────────────────────────────────────  │    │
│  │                                                                         │    │
│  │  Why this is defensible:                                                │    │
│  │  • Documentation gaps are well-established in literature                │    │
│  │  • CC/MCC impact on DRG weight is mathematically certain                │    │
│  │  • Organizations can validate with pre/post CMI comparison              │    │
│  │  • We apply conservative rates at every step                            │    │
│  │                                                                         │    │
│  └─────────────────────────────────────────────────────────────────────────┘    │
│                                                                                 │
│                                                                                 │
│  ┌─────────────────────────────────────────────────────────────────────────┐    │
│  │                                                                         │    │
│  │  DENIAL PREVENTION                                                      │    │
│  │                                                                         │    │
│  │  The mechanism:                                                         │    │
│  │  Payers deny claims for insufficient documentation. Common reasons:     │    │
│  │                                                                         │    │
│  │  • Medical necessity not supported                                      │    │
│  │  • Level of care not justified (IP vs. Observation)                     │    │
│  │  • Clinical indicators not documented                                   │    │
│  │  • Status criteria not met                                              │    │
│  │                                                                         │    │
│  │  These denials often stem from the same root cause as DRG downcoding:   │    │
│  │  documentation gaps. The clinical reasoning was there—it just wasn't    │    │
│  │  captured in the note.                                                  │    │
│  │                                                                         │    │
│  │  Complete documentation from admission through discharge provides       │    │
│  │  contemporaneous evidence of patient acuity and care necessity—         │    │
│  │  critical for both avoiding denials and winning appeals.                │    │
│  │                                                                         │    │
│  │  ─────────────────────────────────────────────────────────────────────  │    │
│  │                                                                         │    │
│  │  Why we combine this with DRG Accuracy:                                 │    │
│  │                                                                         │    │
│  │  DRG downcoding and documentation-related denials share the same        │    │
│  │  root cause. The same complete documentation that improves DRG          │    │
│  │  accuracy also prevents denials.                                        │    │
│  │                                                                         │    │
│  │  Rather than calculate them separately (and risk double-counting),      │    │
│  │  we include denial prevention as part of the DRG Accuracy value         │    │
│  │  through a combined "documentation-driven revenue leakage" framework.   │    │
│  │                                                                         │    │
│  │  ┌─────────────────────────────────────────────────────────────────┐    │    │
│  │  │  DOCUMENTATION-DRIVEN REVENUE LEAKAGE                           │    │    │
│  │  │                                                                 │    │    │
│  │  │  DRG downcoding:          2-4% of inpatient revenue             │    │    │
│  │  │  Denial write-offs:       1-2% of inpatient revenue             │    │    │
│  │  │  ──────────────────────────────────────────────────────────     │    │    │
│  │  │  Combined opportunity:    3-6% of inpatient revenue             │    │    │
│  │  │                                                                 │    │    │
│  │  │  We conservatively estimate Abridge captures 15-25% of this.    │    │    │
│  │  └─────────────────────────────────────────────────────────────────┘    │    │
│  │                                                                         │    │
│  └─────────────────────────────────────────────────────────────────────────┘    │
│                                                                                 │
│                                                                                 │
│  ┌─────────────────────────────────────────────────────────────────────────┐    │
│  │                                                                         │    │
│  │  CDI QUERY REDUCTION                                                    │    │
│  │                                                                         │    │
│  │  The mechanism:                                                         │    │
│  │  Clinical Documentation Improvement (CDI) teams review charts and       │    │
│  │  query physicians to clarify or add documentation that supports         │    │
│  │  accurate coding.                                                       │    │
│  │                                                                         │    │
│  │  Many of these queries are asking physicians to document what they      │    │
│  │  already discussed with the patient:                                    │    │
│  │                                                                         │    │
│  │  "Can you clarify the severity of the patient's malnutrition?"          │    │
│  │  "Please document the clinical indicators for acute respiratory         │    │
│  │   failure."                                                             │    │
│  │  "Can you specify the type of encephalopathy?"                          │    │
│  │                                                                         │    │
│  │  When Abridge captures these clinical discussions in real-time,         │    │
│  │  the query becomes unnecessary. The information is already there.       │    │
│  │                                                                         │    │
│  │  ─────────────────────────────────────────────────────────────────────  │    │
│  │                                                                         │    │
│  │  The calculation:                                                       │    │
│  │                                                                         │    │
│  │  Admissions × Query Rate = Total queries                                │    │
│  │  Total queries × Reduction Rate = Queries avoided                       │    │
│  │  Queries avoided × Cost per Query = Operational savings                 │    │
│  │                                                                         │    │
│  │  ─────────────────────────────────────────────────────────────────────  │    │
│  │                                                                         │    │
│  │  Key assumptions:                                                       │    │
│  │  • Query rate: 20-40% of admissions receive at least one query          │    │
│  │  • Reduction rate: 20-30% of queries could be avoided with better       │    │
│  │    initial documentation                                                │    │
│  │  • Cost per query: $50-$100 (CDI time + physician time + follow-up)     │    │
│  │                                                                         │    │
│  │  ─────────────────────────────────────────────────────────────────────  │    │
│  │                                                                         │    │
│  │  Why this matters beyond the dollars:                                   │    │
│  │                                                                         │    │
│  │  Query reduction isn't just about saving $50 per query. It's about:     │    │
│  │  • Faster DRG finalization                                              │    │
│  │  • Shorter billing cycles                                               │    │
│  │  • Less physician interruption                                          │    │
│  │  • CDI teams focusing on complex cases, not routine clarifications      │    │
│  │                                                                         │    │
│  │  The operational value often exceeds the calculated savings.            │    │
│  │                                                                         │    │
│  └─────────────────────────────────────────────────────────────────────────┘    │
│                                                                                 │
│                                                                                 │
│  ───────────────────────────────────────────────────────────────────────────    │
│                                                                                 │
│  TIME SAVINGS → WELLBEING                                                       │
│  ───────────────────────────────────────────────────────────────────────────    │
│                                                                                 │
│                                                                                 │
│  ┌─────────────────────────────────────────────────────────────────────────┐    │
│  │                                                                         │    │
│  │  CLINICIAN WELLBEING                                                    │    │
│  │                                                                         │    │
│  │  The mechanism:                                                         │    │
│  │  Hospitalists document multiple notes per patient across a stay—        │    │
│  │  H&P at admission, daily progress notes, discharge summary. This        │    │
│  │  adds up.                                                               │    │
│  │                                                                         │    │
│  │  Reducing documentation time per admission gives hospitalists time      │    │
│  │  back. In the inpatient setting, this doesn't translate to "more        │    │
│  │  patients" the way it might in outpatient—hospitalists have a           │    │
│  │  census, not open appointment slots.                                    │    │
│  │                                                                         │    │
│  │  Instead, time savings show up as:                                      │    │
│  │  • Less after-hours documentation                                       │    │
│  │  • More time for patient communication and care coordination            │    │
│  │  • Reduced burnout and improved retention                               │    │
│  │                                                                         │    │
│  │  ─────────────────────────────────────────────────────────────────────  │    │
│  │                                                                         │    │
│  │  The calculation:                                                       │    │
│  │  Same retention model as other settings:                                │    │
│  │                                                                         │    │
│  │  Hospitalists × Turnover Rate × Burnout % × Abridge Impact %            │    │
│  │  × Replacement Cost = Retention Value                                   │    │
│  │                                                                         │    │
│  │  ─────────────────────────────────────────────────────────────────────  │    │
│  │                                                                         │    │
│  │  Why we don't model capacity or LOS:                                    │    │
│  │                                                                         │    │
│  │  Some ROI models claim that faster documentation leads to shorter       │    │
│  │  length of stay. We don't make this claim because:                      │    │
│  │                                                                         │    │
│  │  • LOS is driven by clinical factors, not documentation speed           │    │
│  │  • Discharge timing depends on bed availability, care coordination,     │    │
│  │    insurance authorization, and patient readiness                       │    │
│  │  • The causal chain from "faster notes" to "shorter stays" is too       │    │
│  │    indirect to model credibly                                           │    │
│  │                                                                         │    │
│  │  Could complete documentation support faster discharge planning?        │    │
│  │  Perhaps. But we won't calculate dollars we can't defend.               │    │
│  │                                                                         │    │
│  └─────────────────────────────────────────────────────────────────────────┘    │
│                                                                                 │

│  WHY THE REALIZATION RATE MATTERS                                              │
│                                                                                 │
│  The 50% realization rate on DRG accuracy is our most important                │
│  conservative assumption. Here's why we use it:                                 │
│                                                                                 │
│  Even when documentation improves, not every improvement translates            │
│  to revenue:                                                                   │
│                                                                                 │
│  • Coders may not capture every documented CC/MCC                              │
│  • Some documented conditions don't change the DRG                             │
│  • RAC audits may challenge some claims                                        │
│  • Payer edits may reject some codes                                           │
│  • Retrospective adjustments happen                                            │
│                                                                                 │
│  A 50% haircut accounts for all of this. It's aggressive, but it means         │
│  the number that survives is defensible.                                       │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

│  │  ✗ Length of Stay reduction                                             │    │
│  │    We removed this driver entirely. The claim that "better              │    │

│  │  ✗ Readmission reduction                                                │    │

│                                                                                 │
│  But inflated projections create problems:                                     │
│  • They don't survive CFO scrutiny                                             │
│  • They set unrealistic expectations                                           │
│  • They erode trust when actuals don't match                                   │
│                                                                                 │

│  SUMMARY                                                                        │
│                                                                                 │
│  Inpatient value is fundamentally about documentation accuracy.                │
│                                                                                 │
│  In a DRG-based payment model, you get paid for what you document—not          │
│  for what you discussed, not for what you did, but for what's captured         │
│  in the clinical record.                                                       │
│                                                                                 │
│  Ambient documentation ensures clinical complexity is captured as it's         │
│  discussed—not because we're adding things that weren't there, but             │
│  because we're capturing what actually happened at bedside.                    │
│                                                                                 │
│  The primary value drivers:                                                    │
│                                                                                 │
│  • DRG ACCURACY: Capturing CCs and MCCs that would otherwise be missed         │
│  • CDI EFFICIENCY: Reducing queries by documenting completely upfront          │
│  • DENIAL PREVENTION: Stronger documentation for medical necessity             │
│  • CLINICIAN WELLBEING: Less documentation burden for hospitalists             │
│                                                                                 │
│  What we don't claim:                                                          │
│                                                                                 │
│  • LOS reduction (causal chain too weak)                                       │
│  • Capacity expansion (hospitalists have census, not appointments)             │
│  • Readmission reduction (too many confounding factors)                        │
│                                                                                 │
│  That discipline—claiming what's defensible and nothing more—is the            │
│  methodology.                                                                  │
