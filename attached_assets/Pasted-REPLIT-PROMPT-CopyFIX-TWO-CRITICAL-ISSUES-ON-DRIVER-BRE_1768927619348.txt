ISSUE 2: MATH IS WRONG
PROBLEM: The driver total shows only the first subtotal, not the sum.
Example (Patient Access):

Efficiency gap value: $72,000
Utilization gap value: $270,000
Displayed total: $72,000 ← WRONG
Should be: $342,000

FIX: Update the calculation logic to sum all subtotals.
javascriptCopy// Patient Access calculation
const calculatePatientAccess = (inputs) => {
  // Efficiency gap component
  const efficiencyHours = inputs.efficiencyGapHours; // e.g., 900
  const timeToVisitConversion = inputs.timeToVisitConversion / 100; // e.g., 0.20
  const revenuePerVisit = inputs.revenuePerVisit; // e.g., 200
  
  const efficiencyValue = efficiencyHours * timeToVisitConversion * revenuePerVisit;
  
  // Utilization gap component  
  const utilizationEncounters = inputs.utilizationGapEncounters; // e.g., 6750
  const realizationRate = inputs.realizationRate / 100; // e.g., 0.20
  
  const utilizationValue = utilizationEncounters * realizationRate * revenuePerVisit;
  
  // TOTAL = SUM OF BOTH
  const total = efficiencyValue + utilizationValue;
  
  return {
    efficiencyValue,
    utilizationValue,
    total  // This should be displayed as the driver total
  };
};

1. **Make inputs look like inputs** — borders, backgrounds, hover states
2. **Fix the math** — total = sum of all subtotals
3. **Real-time updates** — when they change a value, everything recalculates
