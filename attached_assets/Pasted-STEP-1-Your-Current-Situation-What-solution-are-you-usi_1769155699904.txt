Replit Prompt: Redesign the Switch Flow
CopyRedesign the Switch flow to be a world-class displacement tool that's conservative, transparent, and irresistibly logical. The goal is that a prospect using a competitor looks at this and thinks "Everything they're saying makes sense. I should explore this."

## CORE PRINCIPLES

1. **Never attack the competitor** — Frame as "you vs. your potential" not "them vs. us"
2. **Conservative by default** — Under-promise, let reality over-deliver
3. **Transparent math** — Show every calculation, cite every benchmark
4. **Tiered confidence** — Separate "we know this" from "we estimate this"
5. **Respectful of their choice** — They made a reasonable decision, we're just showing what's possible
6. **Urgency without pressure** — Show cost of waiting, don't manipulate

CALCULATION LOGIC
javascriptCopy// Gap calculations

function calculateGap(inputs, abridgeBenchmarks) {
  const { providers, encounters, utilization, timeSaved, wrvuBefore, wrvuAfter } = inputs;
  const encountersPerProvider = encounters / providers;
  
  // Utilization Gap
  const abridgeUtilization = abridgeBenchmarks.utilization; // 65%
  const utilizationGapPercent = Math.max(0, abridgeUtilization - utilization);
  const yourEncountersDocumented = encounters * (utilization / 100);
  const abridgeEncountersDocumented = encounters * (abridgeUtilization / 100);
  const utilizationGapEncounters = abridgeEncountersDocumented - yourEncountersDocumented;
  const utilizationGapValue = utilizationGapEncounters * 4; // $4/encounter value
  
  // Efficiency Gap
  const abridgeTimeSaved = abridgeBenchmarks.timeSavedAvg; // 4 min
  const efficiencyGapMinutes = Math.max(0, abridgeTimeSaved - timeSaved);
  const totalEfficiencyGapMinutes = abridgeEncountersDocumented * efficiencyGapMinutes;
  const efficiencyGapHours = totalEfficiencyGapMinutes / 60;
  const efficiencyGapValue = efficiencyGapHours * 150 * 0.25; // $150/hr × 25% conversion
  
  // wRVU Gap (if provided)
  let wrvuGapValue = 0;
  if (wrvuBefore && wrvuAfter) {
    const theirLift = wrvuAfter - wrvuBefore;
    const abridgeLiftMin = abridgeBenchmarks.wrvuLiftMin; // 3%
    const theirLiftPercent = (theirLift / wrvuBefore) * 100;
    if (theirLiftPercent < abridgeLiftMin) {
      const gapPercent = abridgeLiftMin - theirLiftPercent;
      const gapWRVU = wrvuBefore * (gapPercent / 100);
      wrvuGapValue = gapWRVU * abridgeEncountersDocumented * 33 * 0.5;
    }
  }
  
  // Tier 1 Total
  const tier1Total = utilizationGapValue + efficiencyGapValue + wrvuGapValue;
  
  // Capture Rate
  const utilizationCapture = (utilization / abridgeUtilization) * 100;
  const efficiencyCapture = (timeSaved / abridgeTimeSaved) * 100;
  const combinedCapture = (utilizationCapture / 100) * (efficiencyCapture / 100) * 100;
  
  // 3-Year Projection
  const annualGap = tier1Total;
  const year1Gap = annualGap * 0.75; // Ramp period
  const year2Gap = annualGap;
  const year3Gap = annualGap;
  const threeYearGap = year1Gap + year2Gap + year3Gap;
  
  // Cost of Waiting
  const monthlyGap = annualGap / 12;
  const wait6MonthsLoss = monthlyGap * 6;
  const wait12MonthsLoss = monthlyGap * 12;
  
  return {
    utilizationGapEncounters,
    utilizationGapValue,
    efficiencyGapHours,
    efficiencyGapValue,
    wrvuGapValue,
    tier1Total,
    utilizationCapture: Math.round(utilizationCapture),
    efficiencyCapture: Math.round(efficiencyCapture),
    combinedCapture: Math.round(combinedCapture),
    annualGap,
    threeYearGap,
    monthlyGap,
    wait6MonthsLoss,
    wait12MonthsLoss,
  };
}

TONE GUIDELINES

Never say "your solution is bad" — say "there's unrealized potential"
Never say "switch to us" — say "here's what's possible"
Always show the math
Always cite the benchmark source
Acknowledge that switching has costs (time, change management)
Be honest about the ramp period — don't promise instant value
