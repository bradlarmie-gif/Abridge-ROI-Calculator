  STEP 4 — Update MeasureInventory.tsx for ED domain labels

  When careSetting === 'ed', the Capacity domain should display as "Throughput" instead of "Capacity". The domain key stays capacity in the data model — only the display label changes.

  In the domain configuration array, add a condition:

  const domainDisplayLabel = (domain: string, setting: string): string => {
    if (domain === 'capacity' && setting === 'ed') return 'Throughput';
    if (domain === 'capacity' && setting === 'inpatient') return 'Patient Flow';
    return domain.charAt(0).toUpperCase() + domain.slice(1);
  };

  Use this function wherever domain labels are rendered in MeasureInventory.

  The ED Throughput domain's primary delta badge (the collapsed header metric) should be lwbsRate if available, falling back to doorToProvider, falling back to patientProviderRatio.
