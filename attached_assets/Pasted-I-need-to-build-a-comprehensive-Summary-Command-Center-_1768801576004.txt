- Show "per staffed bed" and "per nurse" metrics
- Value Story emphasizes "97% from time savings"
- Include "What We Don't Claim" reminder
- Scenarios compare bed counts, not provider counts

FOR INPATIENT:
- Show "per hospitalist" metrics
- Value Story notes that Doc Quality dominates (63%)
- Include honest framing about census being fixed
- Scenarios include CDI-related options

FOR ED:
- Show "per physician" metrics
- Include LWBS and scribe-specific metrics
- Scenarios include throughput and scribe options

1. Tab switching:
   - Smooth fade transition between modes
   - Remember last selected tab in session
   - Deep-linkable URLs (/summary/methodology, etc.)

2. Edit Model button:
   - Returns to Model Builder with all data preserved
   - Changes sync back to Summary automatically

   - Opens modal with driver-specific inputs
   - Updates calculations without full page reload
   - Shows success message with new totals

   - PDF generation with loading state

   - Different templates for Executive vs. Full Detail
   - Include generation timestamp

5. Share:
   - Copy unique URL to clipboard
   - Toast notification "Link copied!"
   - Shared links should be read-only by default

   - Real-time calculation as user types
   - Validation for reasonable inputs
   - "Apply" button to make it the new base model

7. Mobile responsive:
   - Tabs become dropdown on small screens
   - Tables scroll horizontally
   - Comparison view stacks cards vertically

DESIGN SPECIFICATIONS:

1. Colors:
   - Coral (#E85D3F) for accents, key numbers, CTAs
   - White backgrounds
   - Gray (#6B7280) for secondary text
   - Light gray (#F8F9FA) for card backgrounds
   - Green tint for positive metrics, subtle

2. Typography:
   - Large, bold for hero metrics
   - Monospace for calculations/formulas
   - Clear hierarchy in each section

3. Spacing:
   - Generous padding (24-32px)
   - Clear section separation
   - Breathing room around key numbers

4. Cards and containers:
   - Subtle shadows for depth
   - Rounded corners (12px)
   - Consistent padding

5. Tables:
   - Alternating row colors for readability
   - Highlighted "current" column
   - Sticky headers for long tables
