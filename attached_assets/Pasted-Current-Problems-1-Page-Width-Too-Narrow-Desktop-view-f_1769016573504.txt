Desktop view feels cramped
Need wider max-width

2. Quick Mode Analysis Page Still Has "Over Time" Toggle

You want to remove this toggle for Quick mode
The chart should only appear on the Conclusion page ("The cost of staying put")

3. Summary Tab on Conclusion Page is Weak

"The Question" is passive and weak
"Context" section with bullet points feels like disclaimers
"Let's Talk" is too sales-y
Should be one cohesive scrollable page instead of tabs

4. Value Breakdown Drivers Still Showing

Patient Access, Level of Service, Documentation-Related Denials
These are the old arbitrary drivers we said to remove
Should only show for Advanced mode


The Fix:
For Quick Mode Flow:
Page 1: Setup → Sliders for utilization + efficiency, live gap preview
Page 2: Analysis → Show the gaps identified (Utilization, Efficiency bars), estimated annual gap, NO "Over Time" tab, NO driver breakdown
Page 3: Conclusion → The beautiful 3-year chart, Understanding the gap, Cost of waiting, Next steps (no toggle, one scrollable page)
For Advanced Mode Flow:
Page 1: Setup → Detailed metric inputs
Page 2: Analysis → Primary drivers with real math, Operational metrics, Long-term value
Page 3: Conclusion → Same as Quick mode (3-year chart, etc.)

export default function SwitchAmbientConclusion({
  inputs,
  calculations,
  benchmarks,
  mode, // 'quick' | 'advanced'
  onBack
}) {
  
  const [copied, setCopied] = useState(false);
  
  // Calculate ratios
  const utilizationRatio = Math.round((inputs.utilization / benchmarks.utilization) * 100);
  const efficiencyRatio = Math.round((inputs.efficiency / benchmarks.efficiency) * 100);
  const combinedCapture = Math.round((utilizationRatio / 100) * (efficiencyRatio / 100) * 100);
  
  // 3-year calculations
  const year1Gap = calculations.totalAnnualGap;
  const year2Gap = Math.round(year1Gap * 1.10);
  const year3Gap = Math.round(year1Gap * 1.19);
  const threeYearGap = year1Gap + year2Gap + year3Gap;
  
  const monthlyGap = Math.round(year1Gap / 12);
  const sixMonthLoss = monthlyGap * 6;
  const threeYearIfWait = threeYearGap - sixMonthLoss;
  
  // Chart data
  const chartData = [
    { period: 'Today', current: 0, abridge: 0 },
    { period: '3 mo', current: Math.round(year1Gap * 0.12), abridge: Math.round(year1Gap * 0.20) },
    { period: '6 mo', current: Math.round(year1Gap * 0.25), abridge: Math.round(year1Gap * 0.45) },
    { period: 'Year 1', current: Math.round(year1Gap * 0.50), abridge: year1Gap },
    { period: 'Year 2', current: Math.round(year1Gap * 0.50) * 2, abridge: year1Gap + year2Gap },
    { period: 'Year 3', current: Math.round(year1Gap * 0.50) * 3, abridge: threeYearGap }
  ];
  
  const copyLink = () => {
    navigator.clipboard.writeText(window.location.href);
    setCopied(true);
    setTimeout(() => setCopied(false), 2000);
  };
  
  return (
    <div className="switch-page conclusion-page">
      
      {/* Header */}
      <header className="page-header">
        <button className="back-button" onClick={onBack}>
          <ArrowLeft size={16} />
          <span>Back</span>
        </button>
        <div className="header-brand">
          <span className="brand-mark">A</span>
          <span className="brand-label">SWITCH</span>
        </div>
        <div className="progress-indicator">
          <span className="progress-dot complete"></span>
          <span className="progress-dot complete"></span>
          <span className="progress-dot active"></span>
        </div>
      </header>
      
      <main className="page-content wide">
        
        {/* Title */}
        <div className="page-title">
          <h1>The cost of staying put</h1>
          <p className="page-subtitle">
            Cumulative value over 3 years: your current trajectory vs. switching to Abridge
          </p>
        </div>
        
        {/* ===== CHART SECTION ===== */}
        <section className="chart-section">
          <h2 className="section-label">3-YEAR VALUE TRAJECTORY</h2>
          
          <div className="chart-legend">
            <div className="legend-item abridge">
              <span className="legend-line solid"></span>
              <span>Switch to Abridge</span>
            </div>
            <div className="legend-item current">
              <span className="legend-line dashed"></span>
              <span>Stay with current</span>
            </div>
          </div>
          
          <div className="chart-container">
            <ResponsiveContainer width="100%" height={320}>
              <ComposedChart data={chartData} margin={{ top: 20, right: 30, left: 20, bottom: 20 }}>
                <defs>
                  <linearGradient id="abridgeGradient" x1="0" y1="0" x2="0" y2="1">
                    <stop offset="0%" stopColor="#059669" stopOpacity={0.2} />
                    <stop offset="100%" stopColor="#059669" stopOpacity={0.02} />
                  </linearGradient>
                </defs>
                
                <XAxis dataKey="period" axisLine={false} tickLine={false} tick={{ fill: '#64748b', fontSize: 12 }} />
                <YAxis axisLine={false} tickLine={false} tick={{ fill: '#64748b', fontSize: 12 }} tickFormatter={(v) => `$${(v / 1000).toFixed(0)}K`} width={60} />
                
                <Tooltip content={<CustomTooltip />} />

                <Area type="monotone" dataKey="abridge" stroke="#059669" strokeWidth={3} fill="url(#abridgeGradient)" dot={{ fill: '#059669', r: 5 }} />
              </ComposedChart>
            </ResponsiveContainer>
          </div>
          
          <div className="gap-annotation">
            <span className="gap-arrow">↕</span>
            <span className="gap-value">${formatNumber(threeYearGap)}</span>
            <span className="gap-label">3-year gap</span>
          </div>
          
          {/* How it adds up */}
          <div className="ramp-explanation">
            <p><strong>Abridge customers typically see value ramp over time:</strong></p>
            <ul>
              <li><span className="phase">Quick wins (0-3 mo):</span> Utilization jumps as providers adopt</li>
              <li><span className="phase">Optimization (3-12 mo):</span> Efficiency gains compound</li>
              <li><span className="phase">Full ramp (Year 2+):</span> Organization-wide benefits realized</li>
            </ul>
          </div>
        </section>

          </div>

            The gap between these two lines represents unrealized value — not because your current

          </p>
          
          <div className="formula-box">
            <span className="formula">Utilization × Efficiency × Quality = Total Value</span>
            <p className="formula-note">Small gaps in each dimension compound into large gaps overall.</p>
          </div>
          
          <p className="section-insight">
            If your utilization is <strong>{utilizationRatio}%</strong> of potential, and your efficiency 
            is <strong>{efficiencyRatio}%</strong> of potential, you're capturing roughly 
            <strong> {combinedCapture}%</strong> of the value you could be.
          </p>
        </section>

              </div>
              <p className="gap-card-insight">
                You're at <strong>{utilizationRatio}%</strong> of Abridge benchmark
              </p>
            </div>
            
            <div className="gap-card">
              <span className="gap-card-label">EFFICIENCY</span>
              <div className="gap-card-values">
                <span className="value-current">{inputs.efficiency} min</span>
                <span className="value-arrow">→</span>
                <span className="value-benchmark">{benchmarks.efficiency} min</span>
