Fix two issues in the Value Realization Assessment:

## Issue 1: Realization Score Math is Too Harsh

The multiplicative formula (73% × 25% × 60% × 59% = 6%) produces unrealistically low scores. Nobody will believe they're at 6% realized.

### Solution: Use a weighted average instead of pure multiplication

Change the realization score calculation from multiplicative to a weighted average:

```javascript
// OLD (produces unrealistically low scores)
const realizationScore = Math.round(
  (utilizationScore / 100) * 
  (efficiencyScore / 100) * 
  (qualityScore / 100) * 
  (satisfactionScore / 100) * 100
);

// NEW (weighted average - more realistic)
const realizationScore = Math.round(
  (utilizationScore * 0.30) +  // Utilization is 30% of score
  (efficiencyScore * 0.30) +   // Efficiency is 30% of score
  (qualityScore * 0.25) +      // Quality is 25% of score
  (satisfactionScore * 0.15)   // Satisfaction is 15% of score
);
This produces more believable scores:

73% + 25% + 60% + 59% weighted = ~55% realized (vs 6% with multiplication)

Update the maturity spectrum thresholds accordingly:

Under 40%: Early Stage
40-60%: Developing
60-80%: Optimized
80%+: Transformed
