Step 4: The Opportunity at Scale - Complete Replit Specification
Page Overview
Step 4 is a single, focused page with one interactive visualization that lets users explore the value gap at their full organizational scale.
Design Principle: Let them discover the impact themselves through exploration. No pushy language. The math speaks for itself.

Calculation Logic
typescriptCopy// Constants
const ABRIDGE_BENCHMARKS = {
  utilization: 65,
  timeSavedPerEncounter: 3, // minutes
  costPerProviderPerMonth: 180,
};

// Ramp-up factors (% of full value achieved each year)
const RAMP_FACTORS = {
  year1: 0.4,  // 40% of full value
  year2: 0.7,  // 70% of full value
  year3: 1.0,  // 100% of full value
};

// Main calculation function
function calculateAtScale(
  providers: number,
  encounters: number,
  originalCalculations: Calculations,
  originalProviders: number,
  originalEncounters: number
) {
  // Scale factor based on encounters (primary driver of value)
  const scaleFactor = encounters / originalEncounters;
  
  // Scale the annual values
  const scaledAbridgeAnnualValue = originalCalculations.totalAbridgeValue * scaleFactor;
  const scaledDaxAnnualValue = originalCalculations.totalCompetitorValue * scaleFactor;
  
  // Calculate year-by-year (Abridge ramps up, DAX stays flat)
  const year1 = {
    abridge: scaledAbridgeAnnualValue * RAMP_FACTORS.year1,
    dax: scaledDaxAnnualValue,
    gap: (scaledAbridgeAnnualValue * RAMP_FACTORS.year1) - scaledDaxAnnualValue,
  };
  
  const year2 = {
    abridge: scaledAbridgeAnnualValue * RAMP_FACTORS.year2,
    dax: scaledDaxAnnualValue,
    gap: (scaledAbridgeAnnualValue * RAMP_FACTORS.year2) - scaledDaxAnnualValue,
  };
  
  const year3 = {
    abridge: scaledAbridgeAnnualValue * RAMP_FACTORS.year3,
    dax: scaledDaxAnnualValue,
    gap: (scaledAbridgeAnnualValue * RAMP_FACTORS.year3) - scaledDaxAnnualValue,
  };
  
  // Cumulative values for the chart
  const chartData = [
    {
      year: 'Today',
      abridgeCumulative: 0,
      daxCumulative: 0,
    },
    {
      year: 'Year 1',
      abridgeCumulative: year1.abridge,
      daxCumulative: year1.dax,
    },
    {
      year: 'Year 2',
      abridgeCumulative: year1.abridge + year2.abridge,
      daxCumulative: year1.dax + year2.dax,
    },
    {
      year: 'Year 3',
      abridgeCumulative: year1.abridge + year2.abridge + year3.abridge,
      daxCumulative: year1.dax + year2.dax + year3.dax,
    },
  ];
  
  // Total 3-year gap
  const threeYearGap = chartData[3].abridgeCumulative - chartData[3].daxCumulative;
  
  return {
    yearlyData: { year1, year2, year3 },
    chartData,
    threeYearGap,
    scaledAbridgeAnnualValue,
    scaledDaxAnnualValue,
  };
}

// Format currency helper
function formatCurrency(value: number): string {
  if (value >= 1000000) {
    return `$${(value / 1000000).toFixed(1)}M`;
  } else if (value >= 1000) {
    return `$${(value / 1000).toFixed(0)}K`;
  }
  return `$${value.toFixed(0)}`;
}

Summary
This Step 4 design:

Lets them explore via sliders (not pushy)
Shows the divergence visually via the chart (the shaded gap area)
Provides clear numbers via the year-by-year cards
Summarizes simply without dramatic language
Soft CTA that respects their curiosity

The magic moment is when they slide from 50 providers to 500 and watch the gap explode. They discover it themselves. No manipulation needed.
