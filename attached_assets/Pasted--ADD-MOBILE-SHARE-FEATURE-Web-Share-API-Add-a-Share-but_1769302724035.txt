## ADD MOBILE SHARE FEATURE (Web Share API)

Add a "Share" button that uses the native Web Share API on mobile devices. This lets users share the PDF via email, messages, AirDrop, save to files, etc. - all using their device's built-in sharing.

### 1. Create a share handler function

In the summary/results page where the Export PDF button lives, add this function:

const handleSharePdf = async () => {
  setIsExporting(true);
  
  try {
    // Generate the PDF blob (use existing PDF generation logic)
    const blob = await generatePDF(data); // or whatever your existing generate function is
    
    // Create a File object from the blob
    const fileName = `abridge-roi-${careSetting.toLowerCase()}-${new Date().toISOString().split('T')[0]}.pdf`;
    const file = new File([blob], fileName, { type: 'application/pdf' });
    
    // Check if Web Share API supports sharing files
    if (navigator.canShare && navigator.canShare({ files: [file] })) {
      await navigator.share({
        title: `${careSetting} ROI Assessment`,
        text: 'Abridge ROI Assessment - see attached PDF',
        files: [file],
      });
      // Success - user shared or cancelled (both are fine)
    } else {
      // Web Share not supported or can't share files - fall back to download
      saveAs(blob, fileName);
    }
  } catch (err) {
    // User cancelled share or error occurred
    if (err.name !== 'AbortError') {
      // Only show error if it wasn't a user cancellation
      console.error('Share failed:', err);
      toast({
        title: "Share failed",
        description: "Falling back to download...",
        variant: "destructive",
      });
      // Fall back to download
      const blob = await generatePDF(data);
      saveAs(blob, `abridge-roi-${careSetting.toLowerCase()}.pdf`);
    }
  } finally {
    setIsExporting(false);
  }
};

### 2. Add Share button to the UI (mobile only)

Add a Share button that only shows on devices that support Web Share:

// Helper to detect if sharing is available
const canShare = typeof navigator !== 'undefined' && 
                 typeof navigator.share === 'function' &&
                 typeof navigator.canShare === 'function';

// In the actions/buttons section, add:
{canShare && (
  <Button
    variant="outline"
    className="gap-2 border-[#E5E7EB]"
    onClick={handleSharePdf}
    disabled={isExporting}
    data-testid="button-share-pdf"
  >
    <Share2 className="w-4 h-4" />
    Share
  </Button>
)}

// Keep the existing Export PDF button for all devices:
<Button
  variant="outline"
  className="gap-2 border-[#E5E7EB]"
  onClick={handleExportPdf}
  disabled={isExporting}
  data-testid="button-export-pdf"
>
  <FileText className="w-4 h-4" />
  Export PDF
</Button>

### 3. Import Share2 icon

Make sure Share2 is imported from lucide-react:

import { Share2, FileText, /* other icons */ } from "lucide-react";

### 4. Behavior Summary

- On mobile (iOS/Android): User sees both "Share" and "Export PDF" buttons
  - "Share" opens native share sheet (email, messages, AirDrop, save to files, etc.)
  - "Export PDF" downloads directly
  
- On desktop: Only "Export PDF" shows (Web Share typically not supported)

- If share fails or is cancelled: Falls back gracefully to download

### 5. Alternative: Single Smart Button

If you prefer ONE button that's smart about mobile vs desktop:

const handleExportOrShare = async () => {
  setIsExporting(true);
  
  try {
    const blob = await generatePDF(data);
    const fileName = `abridge-roi-${careSetting.toLowerCase()}-${new Date().toISOString().split('T')[0]}.pdf`;
    const file = new File([blob], fileName, { type: 'application/pdf' });
    
    // On mobile with share support, use native share
    const isMobile = /iPhone|iPad|iPod|Android/i.test(navigator.userAgent);
    
    if (isMobile && navigator.canShare && navigator.canShare({ files: [file] })) {
      await navigator.share({
        title: `${careSetting} ROI Assessment`,
        files: [file],
      });
    } else {
      // Desktop or no share support - download
      saveAs(blob, fileName);
    }
  } catch (err) {
    if (err.name !== 'AbortError') {
      // Error (not user cancel) - fall back to download
      const blob = await generatePDF(data);
      saveAs(blob, fileName);
    }
  } finally {
    setIsExporting(false);
  }
};

// Single button that works everywhere:
<Button onClick={handleExportOrShare} disabled={isExporting}>
  <FileText className="w-4 h-4 mr-2" />
  {isExporting ? "Generating..." : "Export PDF"}
</Button>

This approach shows "Export PDF" to everyone but automatically uses the share sheet on mobile.
