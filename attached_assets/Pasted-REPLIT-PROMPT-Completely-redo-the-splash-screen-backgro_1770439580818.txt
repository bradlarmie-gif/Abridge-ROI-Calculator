Completely redo the splash screen background. Don't tile a

APPROACH: Use 2-3 LARGE sections of the pattern image placed 
intentionally around the edges of the screen, partially 
cropped, at a visible-but-not-competing opacity.

Think of it like a magazine layout — the pattern bleeds in 
from the edges.

REMOVE everything currently on the background. Start fresh.

Background: #1A1A1A (solid dark)

ELEMENT 1: TOP-RIGHT PATTERN BLOCK
- Use the abridge-pattern.png image
- Size: approximately 500px × 500px (large)
- Position: top-right corner, bleeding off the edge
  (about 40% of the image is off-screen)
- Apply CSS filter to make it dark-on-dark:
  filter: brightness(0.25) saturate(0);
  This makes the red shapes into a visible dark gray 
  against the #1A1A1A background — like #2A2A2A shapes 
  on #1A1A1A background
- opacity: 0.6 (visible, not subtle — you should clearly 
  see the quarter-circle shapes)
- No repeat — single placement
- Subtle animation:
  animation: float1 30s ease-in-out infinite;
  
  @keyframes float1 {
    0% { transform: translate(0, 0) rotate(0deg); }
    50% { transform: translate(-15px, 10px) rotate(1deg); }
    100% { transform: translate(0, 0) rotate(0deg); }
  }

ELEMENT 2: BOTTOM-LEFT PATTERN BLOCK
- Same image
- Size: approximately 600px × 600px (even larger)
- Position: bottom-left corner, bleeding off the edge
  (about 50% off-screen)
- Same filter: brightness(0.25) saturate(0);
- opacity: 0.5
- Rotated: transform: rotate(180deg)
  (flip it so it's not identical to element 1)
- Subtle animation (slightly different timing):
  animation: float2 35s ease-in-out infinite;
  
  @keyframes float2 {

THE KEY DIFFERENCE FROM BEFORE:

Old approach: Tiny tiled pattern at 10% opacity = invisible
New approach: Large intentional blocks at 50-60% opacity = 
visible brand texture that frames the content

The quarter-circle shapes should be CLEARLY VISIBLE as 
dark gray shapes on the dark background. Think of how 
Apple uses large gradient shapes behind content — they're 
visible, they add depth, they frame the focal point.

The animations are slow and gentle — 25-35 second cycles 
with only 10-15px of movement. Just enough to feel alive.
