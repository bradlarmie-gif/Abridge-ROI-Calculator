javascript// Step 1: Build 37-element cash flow array (month 0 + months 1-36)

cashFlows.push(-implementationFee || 0);
// Months 1-36: each month has BOTH a cost outflow and a value inflow

  // Value: based on actively documenting providers, utilization,

  let monthlyValue = getMonthlyValue(month);
  // NET cash flow for this month
  cashFlows.push(monthlyValue - monthlyCost);
}
// Step 2: Solve for monthly rate r where NPV = 0
// NPV = sum of cashFlows[t] / (1 + r)^t for t = 0..36

// Step 3: Annualize

What's likely wrong right now: The current code probably puts the ENTIRE multi-year investment in Period 0 (like a capital expenditure), then shows only value inflows in subsequent periods. That makes the denominator tiny and IRR absurdly high. Abridge is a subscription — costs must be spread monthly.
