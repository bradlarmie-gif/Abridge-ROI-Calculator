WHY EACH METRIC EXISTS:

CMI → drives DRG accuracy value
  "CMI improved from 1.82 to 1.91 = $X per discharge"

CC/MCC Capture Rate → drives coding accuracy value  
  "CC/MCC rate improved from 62% to 71% = more accurate 
   severity capture"

Denials per 100 → drives denial prevention value
  "Denials dropped from 8.2 to 5.1 per 100 = $X saved"

CDI Queries per 100 → drives CDI efficiency value
  "Queries dropped from 35 to 22 per 100 = CDI team 
   can cover X more cases or reduce by X FTE"

Time in Notes → drives time value (operational savings)
Same-Day Completion → proof metric (shows quality)
After-Hours → proof metric (shows wellbeing impact)

Every field traces to a dollar on the output page.
If it doesn't drive a calculation, it shouldn't be here.
