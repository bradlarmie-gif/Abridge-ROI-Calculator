The Architecture That Needs to Exist                                                                                                                                                                         
                                                                                                                                                                                                               
  Problem 1: Single-Setting Only                                                                                                                                                                               
                                                            
  The whole flow assumes one careSetting. A partner live in ED + outpatient gets two separate, unconnected PDFs. That's not an EBR — that's two calculator outputs stapled together.                           
                                          
  Fix: careSetting becomes an array of active settings. Each setting gets its own data entry and its own value calculation. The output is one combined story with per-setting breakdowns. The maturity stage   
  and phase are computed per-setting (inpatient at month 4 is Phase 1; outpatient at month 18 is Phase 3 — the combined story shows both).                                                                     
                                                                                                                                                                                                               
  Problem 2: No Presentation Mode                                                                                                                                                                              
                                                            
  Right now every screen shows both the inputs and the outputs intermingled. A CSM walking into a CHRO's conference room needs to show a clean, polished story — not a calculator with form fields everywhere. 
                                                            
  Fix: Two modes — Build and Present. Build mode is what CSMs use to enter data (before the meeting or during setup). Present mode hides all input scaffolding and shows just the narrative, visuals, and
  numbers. One button toggles between them.                                                                                                                                                                    
   
  Problem 3: Month-over-Month Is Fake                                                                                                                                                                          
                                                            
  The generateTrendData function creates a smooth easeOutQuad curve from whatever two numbers you enter. It shows this to executives as "Your Journey." This will get caught.                                  
                                                                                                                                                                                                               
  Fix: Real monthly data entry (optional — not required). When monthly data exists, show a real chart with phase markers overlaid. When it doesn't exist, show the honest point-in-time comparison — no
  fabricated curve.

  The Full UX Design                                        
                                                                                                                                                                                                               
  Two Modes                                                 

  ┌─────────────────────────────────────────────────────────────┐                                                                                                                                              
  │  BUILD MODE                    PRESENT MODE                 │
  │  ──────────────────            ────────────────────         │                                                                                                                                              
  │  For CSMs before the EBR.      For the EBR itself.          │
  │  Shows data entry forms.       Full-screen, clean.          │
  │  Progress bar visible.         No form fields visible.      │                                                                                                                                              
  │  Can enter monthly data.       Click through sections.      │                                                                                                                                              
  │  Shows "how we calc this."     Shows story + numbers only.  │                                                                                                                                              
  │                                                             │                                                                                                                                              
  │  [Build]  [Present →]   ← toggle in top-right always       │                                                                                                                                               
  └─────────────────────────────────────────────────────────────┘                                                                                                                                              
                                                                                                                                                                                                               
  Present mode is essentially a slide-show through the same screens, but stripped to just the output panels — no inputs, no methodology accordion by default (available on tap/click if exec asks).            
                                                                                                                                                                                                               
  Multi-Setting Story Structure                                                                                                                                                                                
                                                                                                                                                                                                               
  COMBINED SUMMARY (lead with this)                                                                                                                                                                            
  ─────────────────────────────────                                                                                                                                                                            
  $X – $Y / year  (all settings combined)                   
  [N] total providers · [M] total encounters                                                                                                                                                                   
                                                                                                                                                                                                               
    BY SETTING                                                                                                                                                                                                 
    ─────────────────────────────────────────────────────────                                                                                                                                                  
    OUTPATIENT     Month 14   Phase 3   $A – $B / year                                                                                                                                                         
    INPATIENT      Month 6    Phase 2   $C – $D / year                                                                                                                                                         
    ─────────────────────────────────────────────────────────
    COMBINED                            $X – $Y / year                                                                                                                                                         
                                                                                                                                                                                                               
  Each setting expandable → shows its own domain breakdown                                                                                                                                                     
                                                                                                                                                                                                               
  The phase badge per setting matters for the EBR story — you can say "your outpatient program is in the Capacity phase, your inpatient program just entered Efficiency." This is genuinely useful context for 
  a CHRO or COO.                                                                                                                                                                                               
                                                                                                                                                                                                               
  Month-over-Month View                                                                                                                                                                                        
                                                            
  The key design decision: optional monthly data, honest point-in-time fallback.                                                                                                                               
                                                            
  [ Point-in-Time ]  [ Month-over-Month ]   ← tab toggle
                                                                                                                                                                                                               
  MONTH-OVER-MONTH (when real data present):  
                                                                                                                                                                                                               
    wRVU / Encounter                                                                                                                                                                                           
    │                               ●─────────●  With Abridge                                                                                                                                                  
    │                          ●───╯                                                                                                                                                                           
    │                     ●───╯                                                                                                                                                                                
    3.8 ─────────────────────────────────────────  Non-Abridge baseline
    │    ●─────●─────●─────╯                                                                                                                                                                                   
    │                                                                                                                                                                                                          
    ├── Month 1 ── Month 3 ── Month 6 ── Month 9 ── Month 12                                                                                                                                                   
                                                                                                                                                                                                               
    PHASE MARKERS (vertical lines with labels):                                                                                                                                                                
    │ ←── Phase 1 ──┤── Phase 2 ────┤── Phase 3 ──►                                                                                                                                                            
                                                                                                                                                                                                               
    "Month 6 is when Efficiency gains started compounding."                                                                                                                                                    
                                                                                                                                                                                                               
  Phase markers are computed from the go-live date. They're not data — they're the framework overlaid on the actual data. This is enormously powerful in an EBR because the CSM can say: "see how the gains    
  accelerated right when we expected them to, at the Phase 2 transition."                                                                                                                                      
                                                                                                                                                                                                               
  When no monthly data exists, show the point-in-time tab only. The month-over-month tab shows: "Add monthly data in Build mode to see your trend." Don't fake it.
