PART 9: CALCULATION LOGIC

Quick Mode calculations:
- Providers: User input
- Encounters: (providers × encounters_per_provider_baseline) OR custom
- Utilization: User input via slider
- Eligible encounters: encounters × utilization
- All driver values: Scale proportionally based on eligible encounters
- Retention: Scales with provider count
- Investment: providers × cost_per_provider × 12

Advanced Mode additional calculations:
- If provider breakdown provided: Use weighted averages for encounters and wRVUs
- If custom financial parameters: Override baseline assumptions
- If timeline selected: Prorate Year 1 value based on months remaining

Real-time update behavior:
- Debounce inputs by 300ms
- Update preview table on every change
- Highlight changed values briefly (200ms fade)
- Recalculate all downstream values

PART 10: SAVE BEHAVIOR

When user clicks "Save Scenario":

1. Validate inputs:
   - Scenario name required
   - At least one change from baseline

2. Save to state:
   - Scenario ID (generated)
   - Scenario name
   - Scenario type: "expand_providers"
   - Created timestamp
   - Mode used: "quick" or "advanced"
   - All input values
   - Calculated results

3. Navigate back to Scenario Builder main page

4. Show success toast:
   "✓ Scenario saved: [Scenario Name]"

5. New scenario appears in "YOUR SCENARIOS" list
