## ED METHODOLOGY PDF

### Page 1: Context + Time Value Mechanisms

**Title:** ED: HOW WE THINK ABOUT VALUE
**Subtitle:** A framework for understanding value in high-volume, fast-paced emergency settings

**THE CONTEXT:**
Emergency departments operate differently than any other care setting. High volume, unpredictable flow, and templated workflows mean documentation happens in compressed windows—often after the patient encounter, sometimes hours later.

ED physicians don't lack time per encounter the way outpatient physicians do. They lack time in aggregate—the cumulative burden of documentation across a shift of 20-40 patients creates fatigue, extends shifts, and contributes to the highest burnout rates in medicine.

Value in the ED shows up in two places:

**Two-column boxes:**

| THROUGHPUT & EFFICIENCY | DOCUMENTATION QUALITY |
|------------------------|----------------------|
| LWBS reduction, faster door-to-doc, admission capture. When documentation doesn't bottleneck the department, patients move through faster. The ED is a flow problem—documentation is often the constraint. | E&M accuracy, denial prevention, and downstream inpatient revenue. ED documentation is the foundation for admitted patients—what's captured here affects the entire inpatient stay. |
| Direct, measurable value | Direct + downstream value |

**VALUE MECHANISMS — THROUGHPUT & EFFICIENCY**

**Two-column:**

| LWBS REDUCTION | ADMISSION CAPTURE |
|----------------|-------------------|
| DIRECTLY MEASURABLE | INDIRECTLY ATTRIBUTABLE |
| **THE MECHANISM:** When ED physicians document faster, they can see the next patient sooner. Reduced wait times mean fewer patients leave without being seen. Every LWBS patient is lost revenue and a liability risk. | **THE MECHANISM:** Patients who might be discharged due to documentation burden or shift-end pressure can be properly worked up and admitted when appropriate. Documentation isn't the bottleneck. |
| **THE CALCULATION:** Current LWBS rate × Reduction % (10-30%) × Avg ED revenue per visit = LWBS value | **THE CALCULATION:** Potential admissions captured × Admission revenue = Capture value. This is harder to measure—we show it as directional. |
| **WHY DEFENSIBLE:** LWBS is tracked. Door-to-doc time is tracked. The link between documentation speed and throughput is operational reality. | **WHY DEFENSIBLE:** Requires baseline data on admission patterns. Best validated through physician feedback on "patients I would have admitted with more time." |

**Full-width box:**

| CLINICIAN WELLBEING | CONNECTED TO RETENTION |
|---------------------|------------------------|
| ED has the highest burnout rate of any specialty (65%+). Documentation burden is a primary driver. Time saved per shift directly impacts whether physicians finish on time or stay late charting. |
| Calculation: Same retention model as other settings but with ED-specific defaults: 12% turnover, 50% burnout-related, $500K replacement cost. |

## INPATIENT METHODOLOGY PDF

### Page 1: Context + Documentation Quality Mechanisms

**Title:** INPATIENT: HOW WE THINK ABOUT VALUE
**Subtitle:** A framework for understanding value in DRG-based reimbursement

**THE CONTEXT:**
Inpatient medicine operates on a fundamentally different economic model than outpatient care. Hospitals are paid a fixed amount per admission based on the DRG—the Diagnosis Related Group. That payment is determined by what's documented.

If a condition was discussed at bedside but not documented, it doesn't exist for coding purposes. If clinical complexity isn't captured in the note, the DRG may be assigned lower than warranted.

This is where ambient documentation creates value. Not by adding things that weren't there—but by capturing what was actually discussed.

**Two-column boxes:**

| DOCUMENTATION QUALITY | CLINICIAN WELLBEING |
|----------------------|---------------------|
| DRG accuracy, denial prevention, CDI efficiency. When documentation captures clinical complexity, revenue follows. The notes drive the payment. | Hospitalists document multiple notes per patient—H&P, daily progress, discharge summary. Reducing this burden improves work-life balance and retention. |
| Direct, measurable value | Indirect value (no capacity expansion) |

**VALUE MECHANISMS — DOCUMENTATION QUALITY**

**Two-column:**

| DRG ACCURACY (CC/MCC CAPTURE) | CDI QUERY REDUCTION |
|------------------------------|---------------------|
| DIRECTLY MEASURABLE | DIRECTLY MEASURABLE |
| **THE MECHANISM:** CCs and MCCs increase DRG weight and payment. When hospitalists discuss acute kidney injury, malnutrition, or respiratory failure at bedside but don't fully document it, that complexity isn't coded. Abridge captures these conversations. | **THE MECHANISM:** CDI queries often ask physicians to document what they already discussed. "Can you clarify the severity of malnutrition?" When Abridge captures these discussions, the query becomes unnecessary. |
| **THE CALCULATION:** Admissions × At-risk rate (25%) × Protection rate (20%) × DRG weight increase (0.4) × Base payment ($6K) × Realization (50%) = Value | **THE CALCULATION:** Admissions × Query rate (30%) × Reduction rate (25%) × Cost per query ($50) = Savings |
| **WHY DEFENSIBLE:** Documentation gaps are well-established. CC/MCC impact on DRG weight is mathematical. CMI changes are measurable. | **WHY DEFENSIBLE:** Query volume is tracked. Query types are categorized. Reduction is measurable post-implementation. |

**Full-width box:**

| DENIAL PREVENTION | COMBINED WITH DRG ACCURACY |
|-------------------|---------------------------|
| Documentation gaps cause denials—medical necessity not supported, level of care not justified, clinical indicators missing. The same complete documentation that improves DRG accuracy also prevents denials. We combine these rather than double-count. |
| DRG downcoding: 2-4% of inpatient revenue. Denial write-offs: 1-2%. Combined opportunity: 3-6%. We conservatively estimate Abridge captures 15-25% of this leakage. |

### Page 1: Context + Time Value Mechanisms

**Title:** OUTPATIENT: HOW WE THINK ABOUT VALUE
**Subtitle:** A framework for understanding value when billing creates a clear value chain

**THE CONTEXT:**
Outpatient medicine has the clearest path from documentation time to revenue. Physicians bill for each encounter. More encounters, more wRVUs, more revenue. This billing relationship creates a direct value chain.

When a physician saves 4 minutes per visit, that time can become additional patient capacity, or it can stay in their pocket as work-life balance. Either way, the value is traceable.

Documentation quality also matters—wRVU lift from accurate coding, HCC capture for MA populations, denial prevention. Complete documentation drives complete revenue.

**Two-column boxes:**

| TIME BACK | DOCUMENTATION QUALITY |
|-----------|----------------------|
| Capacity expansion, cost reduction, clinician wellbeing. When documentation is faster, physicians can see more patients, reduce burnout, or both. The time has measurable value. | wRVU accuracy, HCC capture, denial prevention. When documentation is complete, coding is accurate, and revenue follows. The notes drive the billing. |
| Direct, measurable value | Direct, measurable value |

**VALUE MECHANISMS — TIME BACK**

**Two-column:**

| PATIENT ACCESS (CAPACITY) | CLINICIAN WELLBEING |
|--------------------------|---------------------|
| DIRECTLY MEASURABLE | INDIRECTLY ATTRIBUTABLE |
| **THE MECHANISM:** If physicians use saved time to see more patients, that's additional revenue. 4 min/visit × 20 visits = 80 min/day.
