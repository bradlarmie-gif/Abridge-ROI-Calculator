OBJECTIVE:
Build the Scenario Comparison View where users can select 2-3 scenarios and see them side-by-side with detailed analysis. This is the "board presentation" view that helps decision-makers compare options and understand trade-offs.

CRITICAL RULES:
- Match existing brand colors and typography exactly
- Maximum 3 scenarios can be compared at once
- Always include baseline as reference (can be toggled)
- Show clear visual hierarchy for easy scanning
- Generate actionable insights automatically
- Exportable for presentations

1. Main Scenario Builder page → "Compare Selected Scenarios" button
2. Individual scenario card → [Compare] action

- Show those scenarios already checked

PART 7: INSIGHT GENERATION LOGIC

Automatically generate insights based on data:

HIGHEST VALUE INSIGHT:
- Find scenario with highest Net Annual Gain
- Calculate % increase over baseline
- Note investment required

BEST ROI INSIGHT:
- Find scenario with highest ROI
- Calculate % improvement over baseline
- Note if investment changes

RECOMMENDATION LOGIC:
- If "Add Drivers" scenario exists AND has better ROI than expand:
  → Recommend drivers first, then expand
- If "New Care Setting" scenario exists:
  → Note potential for multi-setting deployment
- If only "Expand" scenarios:
  → Recommend based on investment comfort level

TIME TO VALUE:
- Add Drivers: "Immediate"
- Expand Providers: "3-6 months"
- New Care Setting: "6-12 months"
- Combined: Sum of phases
