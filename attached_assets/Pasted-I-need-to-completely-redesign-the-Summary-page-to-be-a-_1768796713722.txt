I need to completely redesign the Summary page to be a "Command Center" with multiple view modes. This is not an endpoint—it's where the real conversation happens.

---

OVERALL CONCEPT:

The Summary page has 5 VIEW MODES accessible via tabs:
1. Executive Summary (default)
2. Detailed Breakdown
3. Methodology
4. Scenario Builder
5. Sensitivity Analysis

All modes share a persistent header showing the key metrics.

DESIGN SPECIFICATIONS:

1. Use the same design language as the rest of the app
   - Coral (#E85D3F) for accents, important numbers, CTAs
   - White backgrounds, subtle gray borders
   - Clean typography, generous whitespace

2. Tabs should feel like a native part of the page
   - Smooth transitions between modes
   - Remember which mode they were in if they navigate away and back

3. Numbers should be easy to scan
   - Large, bold for headline metrics
   - Monospace or tabular for calculations
   - Proper comma formatting for large numbers

4. Expandable sections should animate smoothly

5. Export functionality:
   - PDF should look presentation-ready
   - Include Abridge branding
   - Different PDF templates for Executive vs. Full Detail

6. Mobile considerations:
   - Tabs become a dropdown on small screens
   - Tables scroll horizontally
   - Comparison view stacks vertically

---

INTERACTIONS:

1. "Edit Model" button returns to Model Builder with all data preserved

2. "Add Driver" in Detailed Breakdown:
   - Opens a modal to select additional drivers
   - Asks for driver-specific inputs
   - Updates all calculations without leaving Summary

3. Export buttons:
   - Show loading state while generating
   - PDF opens in new tab
   - Share link copies to clipboard with toast confirmation

4. Scenario Builder custom column:
   - Inputs update calculations in real-time
   - Can save custom scenario for comparison

5. Sensitivity sliders (if we add interactive sliders):
   - Drag to see values change in real-time
   - Snap back to "current" on release (or option to apply)
