## 2. ELIMINATE BOTTOM WHITE SPACE — PAGE BREAK CONTROL

The issue: Content stops mid-page and leaves white space.

Fix: Set page-break-inside: avoid on cards, but if that causes overflow, 
instead let content flow naturally and ADD MORE CONTENT to fill pages.

Option A: Add "Connected Value" section to Page 2 instead of Page 4
Option B: Add "Validation Timelines" table to Page 3 
Option C: Expand the mechanism descriptions with more detail

DO NOT leave 30-50% of any page blank.

If content doesn't fill 4 pages cleanly, either:
- Condense to 3 pages (make it denser)
- Expand to fill 4 pages (add the detailed content from methodology)

## 10. PAGE CONTENT DISTRIBUTION

PAGE 1 should contain:
- Header
- Title + subtitle
- THE CONTEXT (full paragraph)
- TWO VALUE CATEGORIES (side-by-side cards)
- OUR APPROACH callout
- Start of VALUE MECHANISMS section with first 2 mechanisms

PAGE 2 should contain:
- Header
- Remaining 4 value mechanisms (2x2 grid or 3x2)
- WHY POTENTIAL VALUE callout
- THE HONEST LIMITS (3-column)

PAGE 3 should contain:
- Header  
- KEY ASSUMPTIONS intro
- Full assumptions table (all rows)
- WHY WE DEFAULT CONSERVATIVE callout
- CONNECTED VALUE section

PAGE 4 should contain:
- Header
- VALIDATION PATH (2x2 grid)
- VALIDATION TIMELINES table
- SUMMARY section
- Closing quote
- "That honesty is the methodology"

FILL EVERY PAGE. If there's white space, add content or adjust layout.

THE REAL ISSUE
You're caught between two problems:

Page breaks — Content that should stay together is breaking awkwardly
Content volume — Not enough content to fill pages, so you get white space

The solution is not compression—it's proper content distribution.
Think of it like newspaper layout: You have a fixed amount of space (4 pages) and you need to flow content to fill it, sometimes letting things wrap, sometimes holding them together.
Specific instruction for Replit:
CopyFor the methodology PDF, treat it like a magazine layout:

1. Calculate total content height
2. Distribute across 4 pages evenly
3. If a section would leave >20% white space at bottom of page, 
   pull the next section header up to that page
4. Cards and tables can break across pages if needed—just ensure 
   the break happens between rows/items, not mid-item
5. Never leave more than 15% white space at bottom of any page 
   (except the last page where the closing quote should have breathing room
