PROMPT: Build a Premium Scenario Comparison Experience
The Financial Proforma results page has Save as Scenario and Compare buttons, but they barely work. The Compare view either doesn't exist or doesn't function. This needs to become a genuinely premium feature — scenario comparison is THE power move for a CSM sitting with a CFO saying "well what if we did it this way instead?" Here's the full spec:
THE VISION
A user builds a proforma (e.g., 3 care settings, Per Provider pricing at $120/mo). They save it as "Scenario A." Then they go back, change pricing to Per Encounter at $5/encounter, and save as "Scenario B." Then they click Compare and see both scenarios side by side — every KPI, every value driver, every year — with differences highlighted. The CFO looks at this and says "okay, show me what happens at $4/encounter" and 60 seconds later there's a third scenario on screen.
This is how deals get closed.
PART 1: SAVE AS SCENARIO — Fix & Polish
Current state: Modal appears, saves name, shows dark bar with scenario name. Basically works but needs polish.
Fixes needed:

What gets saved: Save EVERYTHING — all care settings, all provider counts, all rollout plans, all pricing (type + amount), all utilization rates, all value driver toggles and their inputs (realization rates, DRG weight, LWBS rate, wRVU lift, etc.), all time allocations, all retention settings. The saved scenario must be a complete snapshot that can be loaded back into the editor.
Scenario metadata: When saving, auto-capture and display:

Pricing model (Per Provider / Per Encounter / Annual License)
Total investment over 3 years
Number of care settings included
Date/time saved


Saved scenario bar improvements:

Show: "SAVED: 🔴 Scenario 1 · Per Provider · $3.9M investment · 3 settings"
Add a "Duplicate & Edit" button — this is the fastest way to create a comparison scenario. User duplicates, changes one variable (pricing, utilization, care settings), saves as new scenario.
Add a "Load" button — loads this scenario back into the editor so you can modify inputs
Keep edit (rename) and trash (delete) icons


Multiple scenarios bar: When 2+ scenarios are saved, show them as tabs or pills in the dark bar:

🔴 Scenario 1 · Per Provider (active)
⚪ Scenario 2 · Per Encounter
⚪ Scenario 3 · Aggressive Ramp
Clicking a pill loads that scenario's results
Max 4 scenarios (more gets cluttered)


Auto-prompt to save: If the user changes any input after loading a scenario, show a subtle prompt: "You've modified Scenario 1. Save as new scenario?" This prevents losing work.

PART 4: SUGGESTED SCENARIOS — Smart Prompts
When a user saves their first scenario, suggest common comparisons:
"Want to explore alternatives?"

💰 "What if pricing changes?" — Duplicate your scenario and switch from Per Provider to Per Encounter (or vice versa)
📈 "What if you expand faster?" — Duplicate and change the rollout plan to a more aggressive ramp
🏥 "What if you add another care setting?" — Duplicate and add Nursing or another department
📉 "What's the conservative case?" — Duplicate and reduce all realization rates by 30%
Each suggestion is a one-click action that duplicates the current scenario, makes the described change, and saves it as a new scenario. The user can then click Compare immediately.
This is the "magic moment" — the user realizes they can model any what-if in seconds.

PART 6: PERSISTENCE

Scenarios should persist in localStorage so they survive page refreshes
Include a "Clear All Scenarios" option in settings or a small "Reset" link
When the user returns to the tool, show a subtle banner: "Welcome back — you have [X] saved scenarios. [View Scenarios]"
Scenarios are tied to the browser — they don't sync across devices (that would require auth)


PART 7: TRANSITIONS & ANIMATIONS
Make the Compare view feel premium:

Entering Compare: Slide transition from the proforma results page — the current scenario slides left and the comparison columns slide in from the right
Adding a scenario column: New column slides in from the right with a subtle fade
Removing a column: Column fades out and remaining columns smoothly resize
Chart overlay: Lines draw in sequentially (Scenario 1 first, then 2, then 3) with a subtle animation — creates a moment of "reveal"
KPI cards: Numbers count up when the Compare view loads (like the existing KPI animations on the proforma)
★ best value indicators: Subtle pulse animation when they appear
All transitions: 300ms ease-in-out. Nothing jarring. Everything smooth.
