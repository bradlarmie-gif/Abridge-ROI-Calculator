Build a single-page “Abridge Outpatient ROI Calculator” web app using React + TypeScript and Tailwind CSS. Use a clean, modern layout with a left-hand input panel and a right-hand results panel with a waterfall chart. Use Recharts (or a similar React chart library) for the chart.

High-level behavior

The app lets a user enter a small set of assumptions about their ambulatory practice and see:

ROI multiple

Total annual financial benefit

Year-1 investment cost

Net value created

Total provider hours reclaimed

Post-Abridge average wRVU per encounter

New effective denial rate

The app also lets the user toggle 6 different ROI “levers” on or off (checkboxes). The waterfall chart and totals update in real time based on which levers are enabled.

All logic runs in the browser; no backend is required.

Calculation logic (TypeScript functions)

Create a central calculateRoi(inputs) function that:

Derives shared values:

encountersWithAbridge = annualOutpatientEncounters * abridgeUtilizationPct

annualAbridgeCost = numProviders * monthlyCostPerProvider * 12 + implementationCostYear1

Patient Access value:

visitDurationHours = avgVisitDurationMinutes / 60

reinvestedHours = totalProviderHoursReclaimed * pctTimeToNewVisits

addedVisits = reinvestedHours / visitDurationHours

patientAccessValue = addedVisits * avgNetRevenuePerVisit

Overtime & Locum savings:

overtimeHoursReduced = totalProviderHoursReclaimed * pctOvertimeReduced

overtimeSavings = overtimeHoursReduced * blendedOvertimeRate

Workforce retention savings:

baselineDepartures = providerCount * baselineAttritionRate

burnoutDepartures = baselineDepartures * pctAttritionLinkedToBurnout

departuresAvoided = burnoutDepartures * pctBurnoutExitsAvoided

workforceSavings = departuresAvoided * costPerDeparture

wRVU & LOS alignment revenue:

postWrvuPerEncounter = baselineWrvuPerEncounter * (1 + pctIncreaseWrvuPerEncounter)

incrementalWrvuPerEncounter = postWrvuPerEncounter - baselineWrvuPerEncounter

totalIncrementalWrvus = incrementalWrvuPerEncounter * encountersWithAbridge

wrvuRevenue = totalIncrementalWrvus * wrvuConversionFactor

Denial reduction revenue:

baselineDeniedRevenue = netCollectibleRevenue * baselineDenialRate

documentationDeniedRevenue = baselineDeniedRevenue * pctDenialsFromDocumentation

denialRevenueRecovered = documentationDeniedRevenue * pctDocDenialsRecovered

newEffectiveDenialRate = (baselineDeniedRevenue - denialRevenueRecovered) / netCollectibleRevenue

Risk adjustment / HCC revenue (simplified):

totalConditions = impactedMaPatients * avgConditionsPerMember

missedConditions = totalConditions * pctConditionsMissed

recapturedConditions = missedConditions * pctMissedConditionsRecaptured

newConditions = totalConditions * pctNewConditionsIdentified

totalImprovedConditions = recapturedConditions + newConditions

rawRafPointsGained = totalImprovedConditions * rafGainPerCondition

rawRafChange = rawRafPointsGained / impactedMaPatients

adjustedRafChange = rawRafChange * (1 - rafRealizationHaircut)

riskAdjAnnualRevenue = impactedMaPatients * adjustedRafChange * pmpmBenchmark * 12

Build a list of levers objects like:

type LeverId = "patientAccess" | "overtime" | "workforce" | "wrvu" | "denials" | "riskAdjustment";
type Lever = { id: LeverId; label: string; value: number; enabled: boolean };


Compute totalAnnualBenefit as the sum of value for all enabled levers.

Compute:

roiMultiple = totalAnnualBenefit / annualAbridgeCost

netValueCreated = totalAnnualBenefit - annualAbridgeCost

Return all these fields so the UI can render them.
