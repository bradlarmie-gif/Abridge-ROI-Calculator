EXPLORE PATH — ADD RIGHT PANEL SUMMARY CARDS
The Pattern:
Each page in Explore should have a sticky right panel that shows a live summary of the values being built. This gives users constant feedback as they make selections.

Styling for All Right Panels:
Container:

Dark background (#1A1A1A)
White primary text
Gray secondary text (#888)
24px padding
12px border-radius
Sticky position (follows scroll)
Width: ~300-350px

Section headers:

"YOUR ROI", "TIME VALUE", etc.
12px, ALL CAPS, white, letter-spacing 1.5px
Subtext: 14px, gray

Hero values:

Large number: 32-48px, red-orange (#E85A2C), bold
Unit text below: 14px, gray

Line items:

Label left, value right
Values: white or red-orange for key figures
"—" in gray for unconfigured drivers

Stat boxes (providers, utilization):

Small cards within the panel
Dark gray background (#2A2A2A)
White text, centered

Disclaimer text:

12px, gray, italic
"All values include conservative realization rates..."

Button:

Full width of panel
Red-orange fill when active
Gray/disabled when incomplete

Replit Implementation Notes:

Create a reusable SummaryPanel component that accepts:

Title
Subtitle
Array of line items (label, value, isHighlight)
Hero value (optional)
Button text and action
Disclaimer text


Each page passes its relevant data to the SummaryPanel
Values update live as user makes selections
On mobile: Panel moves below content (stacks vertically)
