Interactions:

Three sliders that must sum to 100%

When one slider moves, others adjust proportionally
OR: lock individual sliders, remaining ones share the adjustment
Real-time updates as they drag


Each bucket shows calculated impact:

Hard Savings: hours × hourly rate = dollar value
Capacity: hours ÷ time per visit = additional visits (optionally × revenue per visit)
Quality of Life: hours ÷ providers ÷ weeks = hours/week returned per provider


Visual feedback:

Sliders are color-coded (green for Hard Savings, blue for Capacity, warm orange for Quality of Life)
Total bar at bottom fills as they allocate
Numbers update smoothly, not jarringly


Validation:

Must sum to 100% to continue
If they try to advance at 95%, gently prompt them


The reassurance note:

Always visible at bottom
Validates that Quality of Life IS value
Preempts the "but that's not real ROI" objection

Key Calculations
javascript// Total hours saved (from Time in Notes + Work Outside of Work)
const calculateTotalHoursSaved = (state) => {
  const { deployment, metricData } = state;
  const { providers, encounters, utilization } = deployment;
  
  let totalMinutesSaved = 0;
  
  if (metricData.timeInNotes.before && metricData.timeInNotes.after) {
    const minutesSavedPerEncounter = metricData.timeInNotes.before - metricData.timeInNotes.after;
    totalMinutesSaved += minutesSavedPerEncounter * encounters * (utilization / 100);
  }
  
  // Convert to hours
  return totalMinutesSaved / 60;
};

// Time allocation calculations
const calculateTimeAllocationValues = (state) => {
  const totalHours = state.calculatedValues.totalHoursSaved;
  const { hardSavings, capacityUnlocked, qualityOfLife } = state.timeAllocation;
  
  return {
    hardSavings: {
      hours: totalHours * (hardSavings / 100),
      dollarValue: totalHours * (hardSavings / 100) * 150 // $150/hr OT rate
    },
    capacityUnlocked: {
      hours: totalHours * (capacityUnlocked / 100),
      additionalVisits: (totalHours * (capacityUnlocked / 100)) / 0.5 // 30 min per visit
    },
    qualityOfLife: {
      hours: totalHours * (qualityOfLife / 100),
      hoursPerProviderPerWeek: (totalHours * (qualityOfLife / 100)) / state.deployment.providers / 52
    }
  };
};
Slider Interaction (Phase 4)
javascript// Sliders must sum to 100%
// When one changes, redistribute the difference proportionally among others

const handleSliderChange = (changedSlider, newValue) => {
  const currentTotal = hardSavings + capacityUnlocked + qualityOfLife;
  const oldValue = state.timeAllocation[changedSlider];
  const difference = newValue - oldValue;
  
  // Get the other two sliders
  const otherSliders = ['hardSavings', 'capacityUnlocked', 'qualityOfLife']
    .filter(s => s !== changedSlider);
  
  // Distribute the difference proportionally
  const otherTotal = otherSliders.reduce((sum, s) => sum + state.timeAllocation[s], 0);
  
  const newState = { ...state.timeAllocation };
  newState[changedSlider] = newValue;
  
  otherSliders.forEach(slider => {
    const proportion = state.timeAllocation[slider] / otherTotal;
    newState[slider] = Math.max(0, state.timeAllocation[slider] - (difference * proportion));
  });
  
  // Ensure it sums to 100
  // ... rounding logic
  
  setState({ timeAllocation: newState });
};

Edge Cases to Handle

User selects no Operational Efficiency metrics:

Skip Phase 4 entirely
Go directly from Phase 3 to Phase 5
Phase 5 shows financial + quality metrics only, no time allocation section


User has only 1 metric:

Still allow them to complete the flow
Phase 5 adapts to show limited data
Add note: "Add more metrics to strengthen your value story"


User enters zero or negative values:

Validation: before must be > 0, after must be >= 0
If after > before for a metric where improvement means decrease (like Time in Notes), flag it


User tries to navigate away mid-flow:

Prompt: "You have unsaved progress. Leave anyway?"
Consider auto-save to localStorage


User returns to earlier phase and changes selections:

If they unselect a metric they already documented, clear that metric's data
Recalculate totals
