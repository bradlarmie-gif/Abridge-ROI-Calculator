# THE GAP SCREEN — WITH INLINE EDITING
## Complete build prompt. Ambient AI path only.

---

## WHAT THIS SCREEN DOES

Shows the total cost of their current activation level across four domains. Every number on this screen comes directly from their domain inputs — nothing is estimated or assumed without their input.

The inline editing capability lets them calibrate any assumption in real time. When they change a number, everything updates immediately — the domain values, the total, the graph, the cost-of-waiting table.

This is the screen they bring to a CFO meeting.

---

## STATE MANAGEMENT

```typescript
// All values flow from domain screen inputs
// Nothing is hardcoded on this screen

const [isEditing, setIsEditing] = useState(false);

// Editable assumptions — initialized from domain screen values
const [editableInputs, setEditableInputs] = useState({
  capacity: {
    activationLevel: capacityActivation,    // 1 | 2 | 3 | 4
    redeploymentPct: capacityRedeployment,  // from domain screen
    monthlyOT: capacityMonthlyOT,
    monthlyPatients: capacityMonthlyPatients,
    additionalPatients: capacityAdditional,
    revenuePerVisit: capacityRevPerVisit,
  },
  revenue: {
    activationLevel: revenueActivation,
    denialRate: revenueDenialRate,
    claimValue: revenueClaimValue,
    wrvuImprovement: revenueWRVU,
    hccImprovement: revenueHCC,
  },
  workforce: {
    activationLevel: workforceActivation,
    afterHoursPerWeek: workforceAfterHours,
    turnoverRate: workforceTurnover,
    afterHoursReduction: workforceReduction,
    otReduction: workforceOTReduction,
  },
  risk: {
    activationLevel: riskActivation,
    defensibility: riskDefensibility,
    auditReadyPct: riskAuditReady,
    cdiQueryRate: riskCDIRate,
    cdiQueryCost: riskCDICost,
    initiatives: riskInitiatives,
  },
});

// Recalculate all gap values when editableInputs changes
const gapValues = useMemo(() => 
  calculateAllGaps(editableInputs, providers, annualEncounters, utilization, timeSavings),
  [editableInputs, providers, annualEncounters, utilization, timeSavings]
);

const totalAnnualGap = gapValues.capacity + gapValues.revenue + 
                       gapValues.workforce + gapValues.risk;
const haircut = 0.60; // silent, never shown to user
const displayedTotal = Math.round(totalAnnualGap * haircut);
const displayedMonthly = Math.round(displayedTotal / 12);
const displayedDaily = Math.round(displayedTotal / 365);
```

## REAL-TIME UPDATE BEHAVIOR

When ANY input is edited:

```
1. Gap values recalculate immediately (debounce 200ms)
2. Domain breakdown bars re-animate to new widths (300ms)
3. Total in Section 1 re-counts up to new value (600ms)
4. Monthly/weekly/daily breakdowns update instantly
5. Graph redraws with new data points (400ms transition)
6. Cost of waiting table updates all cells
7. Dark card monthly value updates
8. Score on previous screen is NOT retroactively changed
   (score is locked when they advance — editing here is
    about the dollar figures, not the score)
```
