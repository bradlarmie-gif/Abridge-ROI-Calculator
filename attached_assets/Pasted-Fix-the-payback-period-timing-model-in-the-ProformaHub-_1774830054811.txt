  ### Change 4 — Fix adoption ramp to count from onset, not go-live
  In buildMonthlyCashFlows, inside the driver loop, find:                                                                                                                                                      
      const rampMonths = (onset === "immediate" || (onset !== "phased" && onset !== "delayed" && driver.category === "documentation")) ? 1 : implRampMonths;
      const adoptionRamp = getAdoptionRamp(monthsSinceGoLive, rampMonths);                                                                                                                                     
  Replace with:                                                                                                                                                                                                
      const delayMonths = ONSET_DELAY_MONTHS[onset] || 0;                                                                                                                                                      
      const monthsSinceOnset = monthsSinceGoLive - delayMonths;                                                                                                                                                
      const rampMonths = onset === "phased" ? implRampMonths : 3;                                                                                                                                              
      const adoptionRamp = getAdoptionRamp(monthsSinceOnset, rampMonths);                                                                                                                                      
  Why: This was the core bug. With `rampMonths = 1` for "immediate", docs reached 100% value by month 2. And for "delayed", the ramp was consumed DURING the delay — so at month 3 the ramp(3, 3) = 100%,

Now the 3-month sigmoid ramp starts AFTER the delay ends, for all non-phased drivers.
